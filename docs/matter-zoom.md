# 확대! 물질 탐험 연구소 — 직접 누르는 확대 관찰

운영 경로: [프로그램 실행](https://scilab-platform.vercel.app/run/matter-zoom) · [직접 실행](https://scilab-platform.vercel.app/labs/matter-zoom/index.html) · 소개 `/programs/matter-zoom`

## 이번 변경

사용자의 요청에 따라 전자 껍질·전자배치 활동을 제거하고 관찰 그림을 중심으로 화면을 정리했다. 중학교 2학년이 기본 수준이다.

- 전자배치 버튼·드래그·완성 모형·최외각 전자 설명·인쇄 기록을 제거했다. 원자 모형의 원형 궤도선도 없앴다.
- 물질 사진을 누르면 확대된다. 분자·원자 위에 확대할 수 있다는 표시를 붙이고 이름을 그림 가까이에 표시한다.
- 물·수소의 분자 속 원자를 누르면 원자 내부가 바로 열린다. 금 배열의 원자를 선택해도 바로 내부가 열린다. 원자 구 하나만 보여 주던 중간 화면을 생략했다.
- 가운데 원자핵을 누르면 원자핵이 확대된다. 확대된 원자핵의 +·0 입자 또는 그림 아래 입자 버튼을 누르면 선택한 종류가 강조되고 바로 아래에 설명이 나온다.
- 원자핵을 보다가 전자를 선택하면 원자 전체로 돌아와 주변의 전자를 강조한다. 없는 중성자를 만들어 그리지 않는다.
- 별도 옆 설명 패널과 ‘지금 할 일’ 패널을 한 관찰 화면으로 합쳤다. 교사용 링크·기록 등은 상단 메뉴에서 연다.
- 원소 비교·원자 번호·전기적 중성을 선택하면 같은 공간에서 화면이 전환된다. 원자 관찰로 돌아오면 선택한 물질과 원자를 유지한다.
- 정답·점수·필수 클릭 수로 이동을 막지 않는다.

## 물질별 경로

| 물질 | 직접 선택하는 확대 경로 |
|---|---|
| 물 | 물방울 → 물 분자들 → 물 분자 하나 → H 또는 O 선택 → 원자 내부 → 원자핵 |
| 수소 기체 | 기체 용기 → 수소 분자들 → H₂ 하나 → H 선택 → 원자 내부 → 원자핵 |
| 금 | 금 조각 → 반복된 금 원자 배열 → Au 선택 → 원자 내부 → 원자핵 |

입자 이름·전기적 성질은 양성자 +, 중성자 0, 전자 −로 텍스트와 기호를 함께 표시한다. 물 분자를 ‘물 원자’로 표현하지 않는다. 색과 입자 크기·간격은 실제가 아닌 설명용 모형임을 알린다.

## 연결된 개념

- **원소 비교:** H·O·Au의 원자핵과 양성자 1·8·79개를 동시에 비교한다. 전자 수가 다른 Na와 Na⁺도 같은 원소임을 선택해서 확인한다.
- **원자 번호:** 양성자 그림·개수·원자 번호·원소 이름이 함께 바뀐다. 슬라이더·이전/다음 버튼·실제 족과 주기 위치의 1~20 주기율표를 사용할 수 있다. 금은 79번으로 표 범위 밖임을 안내한다.
- **전기적 중성:** 현재 원자의 +와 −를 같은 수로 짝지어 전하 합이 0임을 표시한다. 선택 확장에서는 Na⁺와 Cl⁻의 실제 입자 수를 확인한다.
- **고등학교 선택 확장:** 같은 확대 경험에서 탄소-12·탄소-13의 중성자 수와 질량수를 비교한다. 전자 껍질 내용은 고등학교 수준에서도 제공하지 않는다.

## 여러 교사와 학급

상단 **메뉴 → 반별 수업 링크 만들기**에서 수준을 정하고 반 이름을 한 줄에 하나씩 입력한다. 최대 12개 링크를 만들며, 같은 반 이름이어도 암호학적 무작위 128비트 ID가 각각 부여된다. 이전 수업을 이어서 하려면 같은 링크를 다시 사용한다.

기록은 학생의 현재 브라우저에 수업 ID·수준별로 저장된다. 공용 기기에서는 이어서 하기 또는 새 학생으로 시작을 선택한다. 다른 반의 기록을 초기화하지 않는다. 서버 수업방·학생 명단·교사별 결과 집계는 제공하지 않는다.

v2·v3·v4 기록은 v5 관찰 상태로 복원한다. 물질·원자·입자 관찰 기록은 유지하고, 예전 껍질 화면·전자배치 기록·평가 완료 상태는 제외한다. 사라진 원자 구 화면의 저장 위치는 원자 내부로 연결한다.

## 과학적 검토

- 수소 원자의 예: 양성자 1, 중성자 0, 전자 1. 산소: 8, 8, 8. 금: 79, 118, 79. 중성자 수는 해당 원자의 예이며 원소의 고정 값으로 가르치지 않는다.
- 금 내부 그림은 일부 입자만 표시하며 실제 입자 수를 별도 표시한다.
- 전자는 원자핵 주변의 불규칙한 위치에 표시한다. 원형 궤도·껍질·정해진 경로를 그리지 않고, 위치가 고정된 것이 아님을 안내한다. 확률 밀도나 실제 촬영 영상으로 주장하지 않는다.
- 분자·금속에서 선택해 보여 주는 내부는 독립된 중성 원자의 단순화 모형이다. 실제 결합·공유 전자·금속 전자의 이동은 표현하지 않는다.
- Na⁺는 양성자 11·전자 10, Cl⁻는 양성자 17·전자 18. 양성자 수와 원소의 종류는 유지된다.
- 번호 조작은 서로 다른 원자의 모형을 비교하는 것이며 실제 원자핵을 바꾸는 실험이 아니다.

## 검증

- 상태 복원·반별 링크·카탈로그 갱신에 관련된 자동 테스트 16개 통과.
- 실제 브라우저에서 물·수소·금의 직접 확대와 원자핵/전자 전환, 3개 개념 화면, 1~20 표 선택, Na⁺ 입자 수, 키보드 조작과 확대 애니메이션을 확인했다.
- 360·390·768·1366px 관찰 화면과 3개 개념 화면에서 총 21개 가로 넘침 검사가 통과했다. 같은 이름의 반별 링크 분리·수준 분리·v4 전자배치 기록 이관도 통과했다. 브라우저 오류는 없었다.

## 남아 있는 확인

- 실제 중2 학생이 설명 없이 눌러야 할 대상을 알아보는지 수업 관찰이 필요하다. 자동 동작 검사만으로 직관성·학습 효과를 입증하지 않는다.
- 실제 iPad/Safari, 학교 동시 접속 환경은 별도 확인이 남아 있다.
- 기록은 현재 브라우저에 저장되므로 기기 변경이나 브라우저 저장 공간 삭제 시 이어지지 않는다.
