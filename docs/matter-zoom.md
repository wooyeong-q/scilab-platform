# 확대! 물질 탐험 연구소 구현 보고

## 프로그램 경로

- 운영 실행: [https://scilab-platform.vercel.app/run/matter-zoom](https://scilab-platform.vercel.app/run/matter-zoom)
- 소개: `/programs/matter-zoom`
- 직접 실행: `/labs/matter-zoom/index.html`
- 프로그램 ID: `matter-zoom`

중학교 2학년을 기본으로 하는 확대 관찰 프로그램이다. 물·수소 기체·금을 고른 뒤 분자 또는 원자 배열, 원자 하나, 원자 내부로 들어간다. 확대 모형과 현재 할 일을 한 관찰 작업대에 보여 준다. 원자 내부에 도달하면 원소 비교·원자 번호·전하·전자 배치를 자유롭게 열어 볼 수 있다.

이번 개편에서 순서대로 통과하던 6개 학습 챕터와 원자 개수·원소 종류 수 정답 검사, 세 기준 분류 제출, 카드 정렬 제출, 번호 예측 제출, 전하 판단 제출, 종합 평가를 화면에서 제거했다. 정답이나 점수가 다음 관찰을 막지 않는다. 분자 속 원자 개수와 종류는 모형 옆의 설명으로 확인한다.

## 학습 수준과 여러 교사의 사용

| 수준 | 공통 경험 | 선택해서 펼치는 추가 내용 |
|---|---|---|
| 중학교 · 기본 | 물질 확대, 원자·분자 구분, 원자핵·전자와 세 구성 입자, 원소와 양성자 수, 원자 번호, 중성, 1~20 주기율표·단순 전자 배치 | 전자 수가 다른 같은 원소, Na·Cl의 이온 모형 |
| 고등학교 · 확장 | 같은 확대 작업대와 자유 개념 탐색 | 탄소-12·13 동위 원소와 질량수, 최외각 전자·족·주기 비교 |

전자 배치와 이온은 중2에서 학생이나 교사가 필요에 따라 열어 보는 내용이다. 고등학교 확장에서도 추가 내용을 반드시 풀거나 완료하도록 요구하지 않는다. 고등학교 전체 과정을 대체하지 않으며 오비탈·양자수·전자 확률 분포 계산을 다루지 않는다.

상단 **수업 링크 만들기**에서 수준과 반 이름을 입력하면 한 번에 최대 12반의 공개 링크를 만든다. 링크마다 안전한 난수로 만든 128비트 수업 ID를 사용하므로 서로 모르는 교사가 같은 반 이름을 입력해도 각각 독립된 링크가 만들어진다. 한 교사의 여러 반, 같은 반의 새 수업도 새 링크로 구분한다. 이어서 하는 수업에서는 이전 링크를 사용한다.

기록은 수업 ID·수준에 따라 학생의 브라우저에 따로 저장한다. 저장 키 형식 `scilab-matter-zoom-v2:<수업 ID>:<수준>`은 유지하며 저장 데이터 버전은 4다. 학생 계정·교사별 관리 계정·명단·반 전체 성적 집계는 제공하지 않는다. 공개 링크는 수업 설정을 전달하고 이 기기의 기록을 구분하는 주소다. 다른 학생 기기의 기록을 열거나 수정하는 기능은 없다.

공용 기기에서 기록이 남아 있으면 **내 관찰 이어서 보기 / 새 학생으로 시작**을 먼저 선택한다. 초기화는 현재 수업·수준의 이 기기 기록에만 적용된다. 반별 링크에서 다른 수준을 선택하면 기존 반 기록을 보관하고 선택한 수준의 개인 탐험으로 이동한다. 브라우저 저장 공간을 사용할 수 없어도 관찰은 계속할 수 있다.

같은 수준의 v2·v3 저장은 관찰 물질, 확대 위치, 선택한 분자·배열 위치, 살펴본 입자, 주기율표·전자 배치 연습 기록을 허용된 값만 골라 이관한다. 예전 챕터 번호·해제 상태·정답·종합 평가·완료 상태는 새 관찰 상태에 넣지 않는다. 다른 수준의 저장이나 손상된 JSON은 새 관찰 상태로 처리한다. 이전 금 관찰의 분자 선택 위치는 새 원자 선택 경로에 맞춰 정규화한다.

## 확대 탐험 단계

| 관찰 수준 | 물 | 수소 기체 | 금 | 지금 할 일 |
|---|---|---|---|---|
| 실제 물질 | 물방울 일러스트 | 무색 기체가 담긴 용기 일러스트 | 금 조각 일러스트 | 물질 확대 버튼 누르기 |
| 물질을 이루는 입자 | 여러 H₂O 분자 | 여러 H₂ 분자 | 반복된 Au 원자 배열 | 분자 또는 금 원자 하나 선택 |
| 분자 하나 | H 2개와 O 1개가 결합한 H₂O | H 2개가 결합한 H₂ | 배열에서 원자 하나를 고르면 원자 화면으로 이동 | 관찰할 원자 선택 |
| 원자 하나 | H 또는 O | H | Au | 원자 내부로 확대 |
| 원자 내부 | 가운데 원자핵과 주변 전자 | 양성자 1개와 전자 1개 | 일부 입자와 전체 개수 | +·0·− 입자 선택 |
| 원자핵 | 양성자·중성자 | 가장 흔한 수소 예의 양성자 1개, 중성자 0개 | 양성자·중성자 일부 표시 | 원자핵 입자 관찰·펼쳐 보기 |

물질을 선택하면 실물 일러스트를 먼저 보여 주고 학생이 확대를 시작한다. 선택한 입자를 중심으로 짧은 확대 애니메이션을 적용한다. 모형 자체를 눌러도 선택할 수 있고, 화면 위 **지금 할 일** 영역의 버튼으로도 같은 행동을 할 수 있다. 돌아가기와 물질 다시 선택을 제공한다. 지나온 주요 확대 위치는 경로 표시로 다시 열 수 있다. 금 원자에서 바깥으로 돌아가면 금 원자 배열로 이동한다. 모션 감소 설정에서는 확대 애니메이션을 생략한다.

물 분자 화면은 H·O가 서로 다른 원자의 종류이며 이 종류를 원소라고 설명한다. 수소 분자는 원자 2개로 이루어졌지만 원소의 종류는 수소 한 가지임을 보여 준다. 학생에게 개수를 제출하게 하지 않는다. 금은 분자 묶음으로 표시하지 않는다.

+·0·− 입자나 해당 버튼을 누르면 양성자·중성자·전자라는 이름, 위치, 전기적 성질을 본문에서 확인한다. 양성자 설명에서는 현재 양성자 수→원소 이름→원자 번호를 직접 연결하고, 전자 설명에서는 현재 원자의 양성자·전자 수가 같아 중성임을 연결한다. 아직 누르지 않은 입자는 기호를 먼저 보여 준다. 숫자·기호·텍스트를 함께 사용하여 색만으로 입자를 구분하지 않는다.

## 관찰한 원자로 더 알아보기

원자 내부 아래의 네 질문은 원하는 것을 자유롭게 열고 닫는다. 기존 관찰 화면은 남아 있어 확대 경험과 개념을 함께 볼 수 있다.

| 질문 | 실제 조작과 개념 연결 |
|---|---|
| 왜 서로 다른 원소일까? | H·O·Au를 선택해 원자핵과 양성자 수 1·8·79를 비교한다. 양성자 수가 원소 종류를 결정함을 설명한다. Na와 Na⁺는 전자 수가 달라도 같은 양성자 11개를 가진다는 추가 설명을 펼칠 수 있다. |
| 양성자 수와 표의 숫자 | 현재 원자의 양성자 수와 원자 번호를 연결한다. 1~20 범위 슬라이더·이전/다음 버튼·주기율표 원소 칸을 누르면 양성자 수, 원자 번호, 이름, 기호가 함께 바뀐다. `1 → 수소, 2 → 헬륨, 3 → 리튬`을 차례로 비교한다. 숫자를 입력하거나 배열 순서를 제출하지 않는다. |
| +와 −인데 왜 중성일까? | 방금 관찰한 중성 원자의 양성자·전자 수와 +·− 짝을 보여 준다. 추가 내용을 펼치면 Na가 전자 1개를 잃는 경우와 Cl이 전자 1개를 얻는 경우를 전환하여 남는 전하와 원소·원자 번호가 유지됨을 확인한다. |
| 전자들은 어떻게 놓일까? | 원자번호 1~20 중성 원자를 골라 전자를 껍질로 끌어 놓거나 ＋·− 버튼으로 배치한다. **배치 모형 바로 보기**로 현재 원자의 배치를 즉시 확인할 수도 있다. 전체 배치가 맞으면 제출 없이 배치를 표시하고 기록한다. |

전자 배치는 H·He·Li·O·Ne·Na·K·Ca 바로가기와 1~20 전체 선택을 지원한다. He→Li와 Ne→Na의 배치를 나란히 보여 다음 껍질이 시작되는 규칙을 비교할 수 있다. 안쪽 껍질을 채우지 않고 바깥에 놓거나 범위보다 많은 전자를 놓으면 조작 방법을 설명한다. 이 제한은 선택한 모형의 유효한 배치를 만드는 규칙이며 다른 개념 탐색이나 확대 이동을 잠그지 않는다.

고등학교에서는 탄소-12·13의 같은 양성자 6개와 다른 중성자 6·7개, 질량수 12·13을 펼쳐 비교한다. 전자 배치의 Li·Na·K, F·Cl, He·Ne·Ar에서 최외각 전자·주기·족도 추가로 펼쳐 볼 수 있다. 헬륨은 첫 껍질의 전자 2개로 채워진 18족 원소임을 별도로 설명한다.

종합 문제나 통과 점수는 제공하지 않는다. 이번 요청에 맞춰 학생이 직접 확대하고 원자를 비교하는 경험을 중심으로 재구성했다. **나의 관찰 기록**은 살펴본 물질과 개념, 전자 배치를 자동 저장하고 열람·인쇄하는 기능이며 성취 판정이나 평가 결과가 아니다. 특정 학습지·교과서 페이지·학교 수업 순서에 의존하지 않는다.

## 과학적 표현 검토

| 항목 | 적용 결과 |
|---|---|
| 물·수소 | 물은 H₂O 분자, 수소 기체는 H₂ 분자로 표현한다. 물 원자라는 표현을 사용하지 않는다. 수소 기체는 무색이며 실물 시작 화면은 유리 용기 일러스트다. |
| 금 | 금 원자들이 반복된 배열로 표현한다. 입체 금속 구조를 평면으로 단순화했다고 안내한다. |
| 원자 내부 전환 | 분자 속 공유 전자와 금속에서의 전자 이동을 생략한 독립된 중성 원자 모형으로 전환한다고 안내한다. |
| 원자핵과 입자 | 양성자·중성자는 원자핵, 전자는 주변에 표시한다. 가장 흔한 수소 원자는 중성자 0개인 예외를 명시한다. |
| 전기적 성질 | 양성자 +, 중성자 0, 전자 −를 표시한다. 양성자와 전자의 전하 크기가 같고 부호가 반대라 같은 수이면 중성임을 설명한다. |
| 원소·원자 번호 | 원소 종류는 양성자 수로 결정되고 원자 번호는 양성자 수와 같다고 연결한다. 전자 수가 바뀌어도 원소·원자 번호가 유지됨을 추가 사례로 보여 준다. |
| 중성자 수 | 원소마다 고정된 수가 아니라 해당 원자의 예로 표시한다. 확대 원자는 H-1, O-16, Au-197의 예이며 각각 중성자 0·8·118개다. |
| 금의 입자 수 | Au 중성 원자는 양성자 79·중성자 118·전자 79개로 표시한다. 모형에는 일부 입자만 그렸다고 안내하며 금을 1~20 전자 배치 활동에 넣지 않는다. 전하 짝도 20쌍만 그릴 때 일부 표시임을 명시한다. |
| 실제 사진과 모형 | 시작 화면은 사실적인 일러스트다. 원자 모형은 이해를 돕는 표현이며 입자 크기·거리·색·간격이 실제와 다름을 안내한다. |
| 전자 궤도 | 원형 배치는 전자 수를 정리하는 껍질 모형이며 실제 행성 궤도가 아니라고 안내한다. |
| 전자 배치 범위 | 원자번호 1~20의 바닥상태 중성 원자를 사용한다. 첫 껍질 최대 2, 두 번째 최대 8, 이번 활동의 세 번째는 8까지 사용한다. 세 번째 껍질의 일반적 최대 용량이 8이라고 단정하지 않는다. K=2,8,8,1과 Ca=2,8,8,2에서 네 번째 껍질을 포함한다. |
| 주기율표 | H~Ca 20종의 원자 번호·기호·이름을 실제 주기·족 위치로 표시한다. Au는 79번으로 현재 표 범위 밖임을 안내한다. |
| 조작의 의미 | 번호 슬라이더는 다른 원자의 예를 차례로 비교하는 도구이며 실제 원자핵을 바꾸는 실험으로 표현하지 않는다. 전하 짝짓기는 전하의 합을 정리하는 모형이다. |

## 이미지와 남은 확인

물·수소 용기·금의 기존 800×800 WebP 일러스트를 사용한다. 원자·분자·구성 입자·주기율표는 정확한 수와 기호를 사용하는 SVG·HTML이다. 새 개편에서 생성 이미지나 파일 용량 증가가 필요한 자산은 추가하지 않았다.

- 실제 중2 학생이 현재 할 일과 확대 경로를 바로 이해하는지, 관찰 뒤 개념을 설명할 수 있는지는 실제 수업에서 확인해야 한다. 자동 동작 검사만으로 학습 효과를 입증하지 않는다.
- 실제 iPad/Safari와 학교 동시 접속 환경은 실기기 확인이 남아 있다.
- 기록은 현재 브라우저에 저장되므로 저장 공간 삭제·시크릿 모드 종료·다른 기기 이동 시 이어지지 않는다.
- 이 프로그램은 원자 구조를 위한 단순화 모형이며 실제 결합·전자 확률 분포·핵 안정성 계산을 다루지 않는다.
- 이번 버전은 자유 관찰 프로그램이다. 별도 성취 평가와 교사의 학급 관리 기능은 제공하지 않는다.
