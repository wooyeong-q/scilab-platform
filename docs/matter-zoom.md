## 학습 수준과 여러 교사의 수업

| 수준 | 핵심 활동 | 추가 탐구 |
|---|---|---|
| 중학교 · 기본 | 중2 원소·원자·분자, 구성 입자, 원소 분류·원자 번호, 전기적 중성·이온, 1~20 주기율표에서 단서로 원소 찾기 | 단순 껍질 전자 배치. 건너뛰면 종합 분석에서도 배치를 묻지 않는다. |
| 고등학교 · 선택 확장 | 공통 확대·규칙 탐구와 전자 배치, 최외각 전자·족·주기 비교 | 화학 선택과목의 질량수·동위 원소 비교. 질량수 답을 생략해도 분석 완료 가능 |

고등학교 전체 교육과정이나 특정 선택과목 전체를 대체하는 프로그램은 아니다. 양자수·오비탈·전자 확률 분포는 요구하지 않는다. 중학교 기본 화면에서 질량수·동위 원소를 필수로 평가하지 않는다.

상단 **수업 링크 만들기**에서 수준을 정하고 반 이름을 한 줄에 하나씩 입력하면 최대 12개의 링크를 생성한다. 각 링크는 암호학적 무작위 128비트 수업 ID를 가진다. 같은 반 이름을 사용한 서로 다른 교사, 한 교사의 여러 반, 같은 반의 새 수업을 구분한다. 이어서 하는 수업은 이전 링크를 다시 사용한다.

진행 기록의 저장 키는 수업 ID와 수준을 포함하며 학생의 브라우저에만 저장된다. 기존 링크와 저장 키 접두사 `scilab-matter-zoom-v2:<수업 ID>:<수준>`은 유지하고, 저장 데이터의 `version`은 3으로 올렸다. 서버 수업방·학생 명단·교사별 조회 권한·반 전체 결과 집계는 제공하지 않는다. 링크는 공개 설정이며 인증 수단이 아니다. 링크를 아는 학생이 열어도 다른 기기의 기록을 읽거나 바꿀 수 없다.

공용 기기에서는 기존 기록이 있으면 **내 기록 이어서 탐험 / 새 학생으로 시작**을 먼저 선택한다. 초기화는 현재 링크·수준의 이 기기 기록에만 적용된다. 반별 링크에서 다른 수준을 선택하면 안내 후 개인 탐험으로 이동하며 기존 반 기록은 보존한다.

같은 수업·수준의 v2 저장은 관찰 물질, 확대 위치, 살펴본 구성 입자, 분자 읽기와 전자 배치 연습 기록을 보존한다. 새 규칙 탐구·지도 과제와 달라진 종합 활동의 예전 정답·완료 상태는 승계하지 않고, 새 흐름의 첫 화면부터 시작한다. 이관 안내를 화면에 표시한다. 다른 수준의 저장, 과거의 전역 저장 키와 손상된 데이터는 현재 수업 기록에 섞지 않는다. v3 복원에서도 분류 세 기준 확인, 정렬 순서, 번호 예측, 전하 판단과 선택 배치 평가의 실제 근거를 재검증한다.

## 구현한 확대 경험

물질 선택과 동시에 실물 일러스트에서 입자 모형으로 전환한다. 선택한 입자를 중심으로 화면을 확대하고 다음 관찰 수준을 같은 화면에 이어서 보여준다. 단계별 바깥으로 이동, 지나온 확대 수준 재방문, 다른 물질 선택을 지원한다. 운영체제의 모션 감소 설정에서는 애니메이션 없이 전환한다.

| 물질 | 확대 경로 | 선택 가능한 원자 |
|---|---|---|
| 물 | 물방울 → 여러 물 분자 → H₂O 한 분자 → 원자 하나 → 내부 → 원자핵 | 수소 H, 산소 O |
| 수소 기체 | 투명한 기체 용기 → 여러 수소 분자 → H₂ 한 분자 → 원자 하나 → 내부 → 원자핵 | 수소 H |
| 금 | 금 조각 → 반복된 금 원자 배열 → 배열의 원자 선택 → 원자 하나 → 내부 → 원자핵 | 금 Au |

모형 속 +·0·− 또는 설명 버튼을 선택하면 양성자·중성자·전자라는 이름, 위치, 전기적 성질, 수를 확인한다. 원자핵 펼치기/다시 모으기와 원자핵 추가 확대를 제공한다. 핵심 발견은 탐험 기록에 저장한다.

## 연결된 6개 학습 화면

1. **물질 확대**: 물·수소 기체·금 중 하나를 선택해 원자 내부까지 관찰한다. 선택한 원자의 +·0·− 입자를 모두 확인하고, 분자 물질이면 원자 개수와 원소 종류 수도 구분한다. 세 물질 전체를 완료할 필요는 없으며 다른 물질은 재방문할 수 있다.
2. **원소 분류 실험**: 이름이 가려진 A·B·C를 전자·중성자·양성자 수로 각각 묶는다. 기준 버튼을 바꾸면 그룹이 재구성되고, 이름 공개로 실제 원소와 대조한다. 세 기준을 모두 시험한 뒤 자신의 규칙을 선택·확인한다. 전자·중성자 기준에서는 반례를 보여 주고, 피드백은 해당 입자를 다시 비교하도록 안내한다.
3. **원소의 번호**: 양성자 수가 다른 O·He·C·H 카드를 눌러 `1, 2, 6, 8` 순서로 놓는다. 실제 원소 번호는 카드의 첫째·둘째·셋째·넷째 자리와 구분한다. H·He·O·Na⁺의 양성자·전자 수와 주기율표의 숫자를 대조하고, 양성자 7·중성자 8·전자 7인 새 입자의 숫자를 입력하며 사용한 규칙도 선택한다. 예측과 근거를 확인한 뒤 ‘원자 번호’라는 이름과 질소 N을 공개한다. 같은 화면의 지도에서 양성자 12개인 Mg, 20개인 Ca를 순서대로 찾는다. 주기율표는 별도 챕터가 아니다.
4. **전하의 규칙**: Na·Na⁺·Cl⁻의 중성·양전하·음전하를 먼저 예상한다. 선택하면 +와 −를 짝지은 그림과 남는 전하를 표시한다. 세 판단을 모두 대조하여 양성자·전자 수가 같으면 중성, 전자가 적으면 +, 많으면 −라는 규칙을 확인한다. 무게 저울이나 실제 입자의 정지 배열을 나타내는 그림은 아니다.
5. **전자 배치 · 선택**: 중2는 배치를 탐험하거나 기본 종합으로 바로 이동한다. 탐험 도중에도 건너뛸 수 있다. 배치를 선택하면 1~20 바닥상태 중성 원자를 드래그·버튼·키보드로 구성하고 He→Li·Ne→Na의 껍질 변화를 비교한다. 이 경로에서는 한 원자의 배치 확인과 Mg의 `2,10` 예상 수정·근거 확인 후 진행한다. 고등학교는 배치 경로를 사용하고 Li·Na·K의 최외각 전자 공통점도 확인한다. F·Cl, He·Ne·Ar도 비교하며 헬륨의 전자 2개 예외를 명시한다.
6. **새 입자 분석**: 중학교는 F·Mg·Na⁺, 고등학교는 C-12·C-13·Cl⁻·Ca²⁺ 사례를 차례로 분석할 수 있다. 기본 평가는 중성 여부·원자 번호·원소와 양성자 수라는 판단 근거다. 중2가 배치를 건너뛰었다면 배치 문항과 완료 요약의 배치를 생략하며, 배치 선택 경로와 고등학교에서는 평가한다. 고등학교 질량수는 선택 문항이며, 시도한 오답은 수정하거나 선택을 해제할 수 있다. 완료 화면은 해당 원자·이온의 기호를 표시한다.

탐험 기록은 별도 학습 챕터가 아니라 언제든 열람·인쇄하는 기록 기능이다. 확인한 개념과 실제 시험한 기준·정렬·번호 예측·지도 과제·전하 판단·확장 선택을 함께 표시한다. 브라우저 자동 저장, 손상된 저장 복구, 활동 근거에 맞는 완료 상태 재검증을 지원한다. 이름·계정·학습지·특정 교과서 페이지를 요구하지 않는다.

### 분류에서 한 번에 달라지는 입자 수

| 비교 입자 | 양성자 | 중성자 예 | 전자 | 비교의 역할 |
|---|---:|---:|---:|---|
| A: 나트륨 원자 Na | 11 | 12 | 11 | 나트륨-23의 중성 원자 |
| B: 나트륨 이온 Na⁺ | 11 | 12 | 10 | A와 전자 수만 다르지만 같은 원소 |
| C: 네온 원자 Ne | 10 | 12 | 10 | B와 양성자 수만 다르며 다른 원소. 네온-22의 예 |

전자 수로 묶으면 B·C가 함께 놓이지만 원소 이름은 다르고, 같은 나트륨 A·B는 나뉜다. 중성자 수로 묶으면 나트륨과 네온이 한 그룹에 섞인다. 양성자 수로 묶을 때 A·B와 C가 원소 이름에 맞게 나뉜다. 기존 H·O·Au의 p·n·e가 모두 함께 달라지는 비교를 분류 근거로 사용하지 않는다. 핵을 바꾸는 과정을 재현하는 활동도 아니다. 같은 양성자·다른 중성자의 탄소-12·13 비교는 고등학교 선택 탐구로 유지한다.

번호 예측에는 실제 질소-15의 입자 수 `p=7, n=8, e=7`을 사용한다. 중성자 수나 양성자·중성자의 합을 원자 번호와 혼동하지 않도록 하면서 실제 존재하는 원자의 예를 사용한다. 전자 수 규칙의 반례는 앞의 Na⁺ 행 `p=11, e=10, 원소 번호=11`에서 확인한다. 중2에서는 동위원소 이름이나 중성자 수를 암기·계산하도록 요구하지 않는다.

## 교육 설계 근거와 해석 범위

- [Adams·Paulson·Wieman(2008), PhET 안내 수준 연구](https://phet.colorado.edu/publications/PERC_Interview_Guidance.pdf)는 사고구술 인터뷰에서 안내 방식과 탐색 양상을 비교한다. 개별 답만 구하도록 안내하면 학생이 그 질문 범위에서 멈추는 양상이 보고되었다. 이번 개편은 먼저 분류 기준을 시험하고 반례를 비교한 다음 규칙을 확인하도록 구성했다. 모든 상황에서 안내를 줄이면 성취가 향상된다는 주장으로 일반화하지 않는다.
- [Podolefsky·Perkins·Adams(2010), 탐색을 돕는 시뮬레이션 요소 연구](https://phet.colorado.edu/publications/prst-per-2010.pdf)는 대학생 파동 간섭 인터뷰 8건 중 마지막 2건을 집중 분석한다. 조작, 결과 변화와 연결된 표상이 질문·의미 구성에 이어지는 과정을 보여 준다. 분류 기준에 따른 그룹 변화와 전하 판단 뒤 짝짓기 결과를 관찰하게 한 설계의 참고 근거이며, 이 프로그램의 중2 학습 효과를 직접 검증한 연구는 아니다.
- [van der Meij·de Jong(2006), 동적 다중 표상 연구](https://research.utwente.nl/en/publications/supporting-students-learning-with-multiple-representations-in-a-d/)는 16~18세 학생 72명의 모멘트 시뮬레이션에서 통합·연동 표상을 분리·비연동 표상과 비교했다. 고복잡도 부분의 영역지식 결과와 주관적 어려움에서 통합·연동 조건이 유리했으며, 표상 번역 결과는 경향 수준이었다. 입자 수·그룹·원소 이름과 주기율표 숫자를 같은 활동 안에서 대조하는 구성에 참고했다. 객관적 인지부하 감소나 국내 중2의 성취 향상을 입증했다고 표현하지 않는다.

위 연구는 설계 판단의 참고 근거다. 이번 구현에서는 실제 입자 수를 자유롭게 바꾸는 원자 제작기 전체를 추가하지 않았으며, 분류 기준 전환·카드 정렬·새 번호 입력·지도 선택·전하 예측으로 정해진 비교 사례를 탐구한다. 효과를 평가하려면 정답 선택 외에 학생 설명, 처음 보는 사례에 대한 적용과 시간이 지난 뒤의 이해도도 별도로 확인해야 한다.
