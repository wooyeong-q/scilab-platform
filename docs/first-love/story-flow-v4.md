# 오늘, 너에게 — 이야기 연결과 탐색 화면 정리

2026-10-21. 사용자 피드백: 관찰 창의 문제 바로가기와 하단 관찰 목록 제거, 남주가 먼저 휴대전화로 벚꽃 아래 약속을 보내는 도입 복원, 갑작스러운 인물 등장과 장소 이동을 전체 단계에서 수정.

## 화면과 조작

- 하단의 관찰 항목 목록, 몇 곳을 살펴봤는지 집계, 일반 사물의 완료 체크를 제거했다. 배경의 사물 점만 눌러 관찰한다.
- 일반 사물 창은 관찰 문장과 돌아가기만 제공한다. 문제/사진/마음노트로 이동하는 바로가기를 제거했다.
- 문제는 해당 목표 사물을 눌렀을 때만 열린다. 도착 대화가 끝나도 자동으로 문제를 열지 않는다. 교사 단계 미리보기도 대화 → 탐색 → 사물 클릭 순서다.
- 상단은 소리와 메뉴만 남겼다. 지난 대화·마음노트는 메뉴 안으로 옮기고, 학교 지도는 장소 이동을 누를 때만 펼친다. 단서가 없을 때는 빈 단서함 버튼을 숨긴다.
- 문자 대화는 말풍선과 보내기 버튼으로, 책갈피의 과거 글씨는 종이로 표시한다. 이때 멀리 있는 서아의 입상은 표시하지 않는다.

## 전 단계 연결

| 구간 | 연결한 상황 |
| --- | --- |
| 도입 | 윤재가 방과 후 벚꽃나무 아래 약속을 먼저 보냄 → 서아 답장 → 발소리 → 도하 등장 → 봉투 도움 제안 → 도하 퇴장 |
| P1 → P2 | 파일에서 반납 메모를 찾음 → 책을 챙겨 교실을 나감 → 도서관 문을 열고 반납대의 시우를 만남 |
| P2 → P3 | 책갈피의 예전 글씨를 읽음 → 뒤에서 문 여는 소리 → 도하가 돌아와 반납 자료와 봉투가 함께 옮겨진 상황 설명 |
| P3 → P4 | 섞인 묶음에서 인수표를 찾음 → 뒤의 전달표와 시우의 원본을 비교할 이유 제시 |
| P4 → P5 | 전달표가 복도 게시판을 가리킴 → 서아가 벚꽃길로 이동한다는 문자 → 문을 잡아 준 친구들을 따라 복도로 나감 |
| P5 → P6 | 교실 반납은 확인했지만 정확한 자료함을 찾을 보관표가 필요함 → 도하가 동아리실 문을 엶 → 확성기 장면 |
| P6 → P7 | 불필요한 준비물을 치우며 친구의 진심을 들음 → 준비대 뒤 보관함과 두 기준을 확인 |
| P7 → P8 | 같은 표식의 인수 기록을 확인하러 복도로 돌아감 → 친구들이 함께 기록을 찾음 |
| P8 → P9 | 자료 묶음과 위치표 방향을 찾음 → 시우가 정리 당시 사진을 보내 줌 → 친구들이 동아리실로 돌아가고 윤재는 교실로 이동 |
| P9 → P10 | 사진과 사물을 대조함 → 서아가 나무 아래 도착했다는 문자 → 기존 단서들을 책상에 모아 마지막 자료함을 찾음 |
| P10 → 고백 | 새 봉투 안의 자기 편지를 회수 → 계단·현관을 지나 벚꽃길 → 발소리에 서아가 돌아봄 → 앞에 서서 고백 |

## 진행과 검증

- 대사별 장소 정보를 사용해 배경을 바꾸고, 중간 재접속에서도 이전 대사의 장소를 복원한다.
- 기존 저장의 대사 순서가 바뀐 경우 해당 대화 묶음 처음부터 재개한다. 풀었던 문제, 단서, 오답, 종료 판정은 유지한다.
- `node --test tests/first-love.test.cjs tests/first-love-client.test.cjs tests/first-love-story.test.cjs`: 12개 통과. 실제 학교 네트워크 부하 측정은 아니다.
- 추가 검증: 문자 대화 범위, 장소 전환 후 재개, 이전 대본 저장 호환, 모든 대면 발화자의 사전 등장과 퇴장, 마지막에 남는 두 주인공.
- 실제 브라우저: 모바일 세로·가로 문자 화면, 도하 등장 전 서술, 대사 중단/이어하기, 관찰 창의 바로가기 제거, P1/P2 사물 클릭 후 제출과 다음 장소 연결, 책갈피 종이 표시를 확인했다. 교사 P6 미리보기의 동아리실 입장 서술과 P10 정답 제출 후 편지 회수 대사까지 확인했다.
- 엔딩 표정 에셋과 오답 경계, 문제·엑셀 계약, 서버·DB·홈페이지 목록은 변경하지 않았다.

- 마지막 실화면 확인 중 브라우저 도구 연결이 반복해서 시간 초과되어 P10 마지막 벚꽃길 전환 화면과 수정본의 배포 후 브라우저 확인은 완료하지 못했다. 대사별 장소 복원과 마지막 벚꽃길 전환은 자동 테스트로 확인했다.

## 조사 표시 가시성 조정 (2026-10-21)

- 목표 사물의 큰 이름표와 반복 강조를 제거하고, 모든 조사 사물에 동일한 돋보기·색·크기를 적용했다. 사진 찾기 단계도 기록 전에는 같은 표시를 사용한다.
- 배경과 구별되는 짙은 녹색과 밝은 테두리로 표시하고, 모바일에서도 누르는 영역은 44×44px로 유지한다. 사물 이름은 마우스 또는 키보드 초점에서 나타난다.
- 실제 브라우저에서 1280×720·390×844 화면을 확인했다. 교실의 여섯 사물을 각각 눌러 일반 관찰/문제가 열리는지, P9 사진 기록 후 체크가 남는지 확인했다.
