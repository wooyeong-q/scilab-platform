# 수업 자료 자산

- `public/labs/first-love/first-love-template.xlsx`: `toSheets(SAMPLE)`의 완전한 시연 자료. 설정·퍼즐·자료·대상·모둠단서·장치 6개 시트. 고정 ID·담당·장소·형식·이야기 제목·장치 값은 회색, 교과 입력란은 연노랑이다.
- `public/labs/first-love/authoring-prompt.txt`: 실제 교과 자료로 P1~P8을 교체하는 AI 작성 프롬프트.
- `public/labs/first-love/guide.html`: 교사 준비, 학생 참여, 양식 규칙, 독립 미리보기, 엔딩과 오답 집계 안내.

기본 엔딩 경계는 `positiveMax: 5`, `neutralMax: 14`다. 0~5회는 미소, 6~14회(10회 포함)는 당황, 15회 이상은 극혐 표정으로 설명한다.

P8의 `조건통과`에는 만족하는 번호만 적는다. 나머지 번호는 모두 유효한 제외 근거이며, 하나 또는 여러 개를 선택해도 인정한다. 예를 들어 `2|3`이면 1번·4번 중 하나 또는 둘 다 정답이다. 함께 선택한 번호는 모두 유효해야 한다. 이 규칙은 교과와 무관하다. 시연 H(0)는 조건 4를 “0이 아닌 3의 배수”로 명확히 하여 `2|3`으로 입력했다.

## 생성·확인

엑셀은 Codex primary runtime의 `@oai/artifact-tool`로 작성하고 재계산·셀 검사·오류값 검사 후 내보냈다. 여섯 시트의 대표 범위를 PNG로 렌더해 글자 잘림, 고정/입력 색 구분, 헤더와 행 높이를 확인했다. `.xlsx` 안에는 계산 수식이나 매크로를 넣지 않았다.

배포용 `.xlsx`를 `lib/first-love/import.mjs`의 `importWorkbook`으로 다시 읽었으며, 반환된 lesson은 현재 SAMPLE과 정확히 일치했다. 경고 없음. 퍼즐 8개, 자료 44개, 대상 20개, 자리별 단서 32개를 확인했다. P9~P10은 시연 문제 행에 추가하지 않았다.

네이티브 Excel·한셀에서 직접 열어 보는 검증은 별도로 수행하지 않았다.

## 2026-10-22 생성된 과학 자료와 작성 프롬프트 점검

사용자가 제공한 물질의 구성 수업 파일을 운영 코드의 `importWorkbook`으로 읽었다. 여섯 시트, 퍼즐 8개, 자료 44개, 대상 20개, 모둠단서 32개이며 경고 없이 통과했다. 장치 값은 배포 양식과 일치했다. 사용자 파일은 검토 자료로만 읽었으며 저장소에 포함하지 않았다.

문제와 자료에서 독립적으로 구한 P1~P7 답안은 게임 판정과 일치했다. P8도 후보별 양성자·전자 수와 입자 구성을 네 조건에 다시 대입했으며 조건통과·제외 근거가 일치했다. 조건을 하나씩 빼면 각각 A/B, A/C, A/D, A/E가 남았다. 파일 구조와 정답 연결은 정상이지만 다음 작성 품질 문제는 구조 검사로 발견되지 않는다.

| 확인한 부분 | 문제와 프롬프트 보완 |
| --- | --- |
| P1 역할 | 자료 담당은 A=1, B=2, C=3, D=4이나 단서는 C/D/B/A 순으로 다른 자리에 있었다. 교차 배분 자체가 오류는 아니지만 담당 친구에게 수치를 물으라는 안내와 어긋난다. 기본 배분은 같은 자리로 맞추고, 의도적인 교차는 정보 소유자를 명시하도록 했다. |
| P2·P5 추론 | 이온식과 대상 이름에 답이 드러나 양성자·전자 수를 계산할 필요가 없었다. 목표가 계산·추론이면 결론 대신 관찰값을 제시하고, 이온식 읽기가 목표라면 목표를 정확하게 쓰도록 했다. |
| 카드 배치 | P3은 A~D/ E~H가 범주별로 묶이고 P6은 A·C·E·G가 모두 유효했다. ID·담당을 보존하면서 내용과 정답을 함께 섞어 패턴만으로 맞히지 못하도록 했다. |
| 화면 명칭 | P2·P5의 T/M, P4의 F 대상ID는 실제 대상 선택지에 별도로 표시되지 않는다. 학생에게 보이는 이름과 선택 목록을 기준으로 설명하도록 했다. |
| P6 힌트3 | 퍼즐 시트 J12가 나머지 카드를 '제외'에 놓으라고 안내한다. 실제 화면에는 순서 칸 네 개만 있고 나머지는 목록에 남긴다. 판정용 '제외'와 화면 조작을 구분했다. |
| P7·P8 기준 | 양성자 수의 홀짝은 제시 규칙으로 판정 가능하지만 원소·원자·이온 이해와의 연결이 약하다. 퍼즐 구조를 채우기 위한 임의 기준을 피하고 학습 목표부터 설계하도록 했다. |
| P8 힌트 | 퍼즐 시트 I14는 네 자리의 조건을 모두 공개하고 J14는 가능 후보 A를 지정한다. 힌트는 정보 수집·판단 방법·실제 조작을 돕고 최종 답과 비공개 조건 전체는 공개하지 않도록 했다. |
| 설정 | B12/B13에 10/29가 남아 있었다. 교사가 다른 기준을 명시하지 않았으면 오래된 양식에도 현재 기본값 5/14를 적용하도록 명확히 했다. |
| 교과 범위·표현 | 파일에 참고 교과 자료가 미첨부라고 표시되어 있어 특정 교과서 범위와의 일치는 확인할 수 없다. 미확인 심화 개념을 필수로 넣지 않도록 하고, p−e는 양성자 전하를 +1로 둔 상대값임을 설명하도록 했다. |

학생 공개 범위는 `playerContent`, 공통 힌트는 `hintsFor`, 실제 입력 방식은 `puzzleHTML`과 대조했다. 기본 검산은 정답 열을 가린 독립 풀이, 자리별 정보 공개, 힌트의 답 노출, 실제 조작 일치 여부로 나누었다. 프롬프트는 이러한 오류를 예방하는 작성 지침이며 생성 결과의 교과 정확성과 난이도를 자동 보증하지 않는다.

과학 용어 검토에는 [IUPAC ion](https://goldbook.iupac.org/terms/view/I03158)과 [IUPAC elementary charge](https://goldbook.iupac.org/terms/view/E02032)를 참고했다. 과학 사실이 틀렸다는 이유로 등록 정답을 바꾼 작업은 아니다.
