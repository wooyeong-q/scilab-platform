# 탐색 클릭 수정 · 2026-10-21

공통 `button:active`가 돋보기의 중앙 정렬 transform을 덮어써 누르는 동안
클릭 영역이 오른쪽 아래로 이동했다. 공통 누름 효과를 위치 변화 없는
테두리 효과로 바꾸고, 돋보기는 아이콘만 눌림 효과를 갖도록 했다.
터치 영역은 48px로 확대했다.

390px 화면에서는 봉투 정리함을 클릭했을 때 인접한 붉은 리본이 열리는
문제도 실제로 재현했다. 그림의 원래 위치를 기준으로 겹치는 표시만
간격을 벌리고, 화면 크기가 바뀔 때 다시 배치한다. 누름 상태에는 위치를
바꾸지 않는다.

검증:
- 모바일 크기(390×844)의 실제 브라우저 UI에서 교실의 여섯 표시를 각각
  한 번 클릭해 올바른 사물/문제가 열리는 것을 확인했다.
- 카드 선택 후 답안 칸 클릭으로 배치 수와 카드 내용이 즉시 반영됐다.
- 수정 후 동아리실의 정리함, 리본, 확성기, 가방, 게시판이 각각 올바른
  내용으로 열리는 것을 확인했다.
- 여섯 장소, 320/375/390/700/1200px에서 표시 간격, 화면 경계,
  원래 위치와의 거리, 반복 배치 안정성을 검사한다.
- 기존 게임·데이터베이스·카탈로그 삭제·빌드 절차 회귀 검사 30개 통과.
- 새 표시 배치 검사 1개 통과. 실제 휴대폰 하드웨어 검사는 수행하지 않았다.

홈 등록용 `catalog-preview-v5.jpg`는 기존 실제 실행 화면 캡처다.
카탈로그 등록은 별도 관리자 작업이며 빌드나 마이그레이션에 추가하지 않았다.
