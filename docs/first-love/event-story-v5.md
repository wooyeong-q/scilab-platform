# 이벤트 준비 사고와 표정·복수 근거 채점

## 이야기

윤재가 먼저 서아에게 방과 후 벚꽃나무 아래에서 만나자는 문자를 보낸다. 편지는 교실 책상 위 자신의 가방에 넣어 두고, 책 두 권만 반납하러 간다. 도하는 지나치게 들떠 작은 이벤트를 준비한다. 윤재는 둘이 직접 이야기하고 싶다고 말한다.

윤재가 도서관에 있는 동안 도하가 리본을 펼치다 가방 손잡이에 걸려 가방이 떨어진다. 도하는 떨어진 종이를 행사 카드와 함께 상자에 넣고 교실 뒤 자료함에 정리한 뒤, 편지가 섞였음을 깨닫는다. 발소리와 도서관 입장 장면 뒤에 당황한 표정으로 사고를 알린다.

편지는 이후 교실의 같은 상자에 머문다. 도서관의 대여표·원본, 복도의 반납 기록, 동아리실의 보관표를 함께 확인해 정확한 상자와 자료함을 찾는다. 사진은 시우가 준비 전에 찍은 것으로 설명한다. 새 봉투로 바꿔 주거나 편지를 친구에게 맡기는 대사는 제거했다. 마지막에는 원래 봉투를 직접 찾아 벚꽃길로 간다.

## 표정

네 캐릭터의 기존 인물·의상에 맞춘 4가지 표정과 정면 극혐 엔딩을 이미지 생성으로 만들었다. 실제 투명도가 있는 WebP다. 각 1024×1536 아틀라스의 4개 표정을 SVG 뷰포트에서 잘라 표시한다. 이미지를 수작업으로 그리거나 확대 생성하지 않았다.

| 인물 | 표정 |
| --- | --- |
| 윤재 | 차분함, 긴장, 당황, 결심한 미소 |
| 서아 | 차분함, 다정한 미소, 궁금함·놀람, 수줍음 |
| 도하 | 평소, 들뜸, 사고 후 당황, 진지한 사과 |
| 시우 | 차분함, 웃음 참기, 걱정, 안심시키는 미소 |

대사별 `expression`을 읽고, 같은 대화 안에서 인물별 마지막 표정을 유지한다. 이어하기도 해당 줄까지의 표정을 복원한다. 문자·책갈피는 인물의 실제 등장으로 표시하지 않는다. 고백 뒤 극혐 표정은 머리와 눈 모두 정면을 향한다.

아틀라스의 열별 인물 중심은 윤재 280/248, 서아 308/238, 도하 302/268, 시우 316/287px다. 512px 셀의 중심에 맞춰 이동하되 먼저 원본 열을 자른다. 도하는 손을 보존하려고 열 경계를 x=541로 잡았다. 다른 인물의 일부가 화면에 나타나지 않는다.

## 후보 추론

P8은 제외 근거를 하나 이상 선택한다. 올바른 근거 하나 또는 여러 개를 인정하며, 선택한 근거 중 틀린 것이 있으면 오답이다. 빈 근거는 미완성으로 처리하여 오답을 늘리지 않는다. 예전 저장 답안의 단일 `reason`도 그대로 읽는다.

교과에 관계없이 엑셀의 기존 `조건통과` 열을 사용한다. `2|3`이면 1번·4번을 어기므로 `[1]`, `[4]`, `[1,4]` 모두 인정한다. 통과 정보와 정답은 학생 응답에 노출하지 않는다. 교사용 안내와 작성 프롬프트에도 같은 규칙을 명시했다.

시연 조건 4는 “0이 아닌 3의 배수”로 범위를 명시했다. H(0)의 통과 번호는 `2|3`이다. 0이 짝수라는 사실과 기존 정수의 배수 정의를 혼동하지 않도록 해설에 적었다. 네 조건 중 하나라도 빠지면 최소 두 후보가 남는 협동 구조는 유지한다.
