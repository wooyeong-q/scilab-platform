# 인물·엔딩 이미지 기록

제작: 이 작업의 내장 imagegen. 외부 사진·배우·기존 캐릭터 이미지를 참조하지 않은 신규 허구 인물이다. 배포 파일은 PNG 결과를 Sharp로 WebP 인코딩했다. 개별 패널은 CSS 배경 위치로 표시하며 얼굴을 변형하지 않는다.

| 파일 | 구성 |
|---|---|
| `public/labs/first-love/assets/cast-v1.webp` | 같은 크기의 4패널: 서윤재, 한서아, 강도하, 차은서 |
| `public/labs/first-love/assets/endings-v1.webp` | 같은 여주·의상·벤치 배경·카메라 구도의 3패널: 화사한 미소, 웃지 못한 당황, 찡그린 강한 거부 |
| `public/labs/first-love/assets/locations-v1.webp` | 교실·도서관·빈 동아리실·운동장 벤치 2×2 배경. 상세 프롬프트는 `location-art.md` |

핵심 제작 지시: 고급 한국 청춘 로맨스 웹툰의 부드러운 채색과 선, 아름다운 남녀 주인공 및 친구들, 학교에 어울리는 단정한 남색 교복, 각자 구별되는 헤어스타일과 인상, 따뜻한 오후 빛, 과장된 하트나 로고/문자 없음. 남주는 검은 머리와 차분한 인상, 여주는 긴 짙은 갈색 머리, 남자 친구는 밝은 갈색 머리와 활달한 미소, 여자 친구는 어두운 단발과 또렷한 인상으로 구성했다.

엔딩 제작 지시: 첫 인물 시트의 여주와 일관성을 유지하고 동일한 구도에서 표정만 명확히 구분. 미소는 눈과 입꼬리가 함께 웃으며, 당황은 크게 뜬 눈과 살짝 벌어진 입으로 웃지 않으며, 거부는 미간·코를 찡그리고 입매를 비튼 반응으로 표현. 모욕적인 대사나 외모 비하 문구 없음.

외부 음원·사진 라이브러리의 재배포 파일은 포함하지 않는다. `sound.mjs`는 코드로 합성한 자체 음계와 효과음을 사용한다.
