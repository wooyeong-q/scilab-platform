# 원자 탐험 연구소 구현 및 검증

## 실행 경로

- 플랫폼 상세: `/programs/atom-explorer`
- 플랫폼 실행: `/run/atom-explorer`
- 독립 실행: `/labs/atom-explorer/index.html`

## 학습 흐름

주변 물질 선택·확대 → 입자 관찰 → 원자핵 분류 → 전기적 성질 측정 → 중성 원자 네 종류 비교 → 양성자·중성자 수 변화 예상 및 비교 → 원자 번호 규칙 및 적용 → 원자 조립 → 전자 배치 → 원소 1~20 탐험 → 종합 미션 → 완료·자유 실험실.

학습지나 특정 교과서에 종속되지 않는다. 정해진 시간, 경쟁 점수, 학생 계정은 사용하지 않는다. 각 단계는 필요한 조작을 마친 뒤 완료되며 이전 단계는 다시 방문할 수 있다.

## 추가 및 변경 파일

- `public/labs/atom-explorer/index.html`: 독립 실행 문서와 도구·단계 탐색.
- `public/labs/atom-explorer/style.css`: 전용 반응형 스타일. 기존 프로그램 CSS와 분리.
- `public/labs/atom-explorer/data.mjs`: 원소 20개, 입자, 생활 예시, 발견 규칙.
- `public/labs/atom-explorer/core.mjs`: 중성 원자 모델, 배치 검증, 저장 데이터 기본 검증.
- `public/labs/atom-explorer/app.js`: 단계별 탐구, 마우스·터치·키보드 조작, 도감, 기록, 복구.
- `public/labs/atom-explorer/program.json`: 플랫폼 카탈로그 메타데이터.
- `scripts/register-atom-explorer.mjs`: 신규 프로그램 한 건만 등록. 같은 ID가 있으면 변경하지 않음.
- `package.json`: 기존 빌드와 DB 검증이 성공한 뒤 카탈로그 등록 실행. 프리뷰에서는 등록하지 않음.
- `lib/programs.ts`: 로컬 개발 환경에서도 신규 프로그램을 확인할 수 있는 메타데이터 연결.
- `tests/atom-explorer.test.cjs`: 데이터·전자 배치·잘못된 배치·등록 보존 검증.
- `tests/helpers.cjs`: 테스트 로더의 JSON 모듈 및 ES 모듈 기본 가져오기 지원.

기존 게임, API, 인증, 데이터베이스 스키마, 공통 실행 UI는 변경하지 않는다.

## 원소 및 임무

수소(H)부터 칼슘(Ca)까지 20개. 실제 주기율표의 주기·족 위치를 유지하며 좁은 화면에서는 표 영역 안에서 가로 스크롤한다.

원자 제작, 양성자 수로 정체 추리, 원자 번호 추리, 빠진 전자 수정, 원자핵 구성 입자 선택, 전자 배치, 두 원소 비교, 생활 속 물질과 중성 원자의 관계 적용 등 8개 유형을 번갈아 제공한다. 임무를 완료한 원소에 탐험 표시가 생긴다. 번호·기호는 탐험 전에도 참고할 수 있다.

## 진행 저장과 부하

`localStorage` 키는 `scilab-atom-explorer-v1`. 단계, 완료 단계, 탐험 원소, 발견 기록, 조립 중 입자·전자 배치, 종합 미션 입력 등을 조작 직후 저장한다. 초기화는 명시적 버튼과 확인을 거친다. 같은 출처의 원본·iframe 실행은 같은 진행을 사용한다.

학생의 탐구 조작은 모두 클라이언트에서 수행한다. 외부 CDN, 폰트, 이미지, 추가 라이브러리, 서버 폴링을 사용하지 않는다. 플랫폼의 기존 카탈로그·조회수 API는 그대로 유지된다. 새 프로그램 정적 파일 전체는 약 64KB이며 실제 동시 접속 100대의 학교 와이파이 부하 테스트를 수행한 것은 아니다.

## 과학 내용 검수

- 모형·확대 장면을 실제 사진이나 현미경 영상으로 설명하지 않는다.
- 원의 경계는 배치 영역이며 전자의 실제 고정 이동 경로가 아니라는 안내를 제공한다.
- 원자 번호를 양성자 수로 정의한다. 중성일 때 전자 수가 같다는 조건을 구별한다.
- 양성자 수 변화와 중성자 수 변화를 별도로 비교한다. 실제로 원자핵 입자를 쉽게 넣고 빼는 과정이라고 설명하지 않는다.
- 가장 흔한 수소 원자에는 중성자가 없다는 예외를 기록에 명시한다.
- 중성자 수는 한 가지 예시일 뿐, 원소마다 유일하게 고정되지 않는다고 안내한다.
- 조립 중 모형을 고전하 이온의 일반적인 상태로 제시하지 않는다. 자유 실험은 중성 원자의 전자 배치에 집중한다.
- K는 2,8,8,1, Ca는 2,8,8,2. 세 번째 영역의 보편적인 최대 수용량이 8이라는 뜻이 아니라고 기록에 명시한다.
- 흑연·합금·물·소금을 구성 원소와 구별한다. 소금 속 입자의 상태와 중성 원자 비교 모형을 구별한다.

## 검증 결과

- TypeScript `tsc --noEmit` 통과.
- 기존 테스트 39개와 신규 테스트 2개, 총 41개 통과.
- Playwright/Chromium으로 프롤로그부터 전체 탐구, 20개 원소 임무, 종합 미션, 자유 실험실을 실제 UI 클릭으로 진행.
- 조립 중 새로고침 후 전자 수 복구, 완료 후 재접속, 발견 기록 6개와 탐험 원소 20개 저장 확인.
- 마우스 드래그, 터치 탭·터치 드래그, 클릭 후 배치 확인.
- 1366·1024·768·390px 화면에서 조립 화면의 가로 넘침 없음.
- 플랫폼 상세 페이지와 기존 iframe 실행 화면에서 신규 프로그램 로딩 확인.
- 브라우저 페이지 오류 없음. 테스트 환경의 한글 글꼴 부재는 검증용 글꼴 주입으로 보완했으며 배포 파일에 외부 폰트를 추가하지 않음.

발견 후 수정: 관찰 모형의 입자 클릭 영역 겹침, 조작 후 키보드 초점 소실, 손상된 JSON 저장 기록 덮어쓰기 방지, 원자 모형 영역 직접 배치, 조립 예시의 중성자 수 확인.

## 한계

실제 학생 대상으로 학습 효과를 측정하지 않았고 실제 아이패드 Safari 기기 검증은 수행하지 않았다. 태블릿 검증은 Chromium 터치 에뮬레이션이다. 진행은 같은 브라우저에 저장되며 다른 기기나 브라우저로 자동 동기화되지 않는다. 브라우저 저장소를 직접 삭제하면 기록이 사라진다.
