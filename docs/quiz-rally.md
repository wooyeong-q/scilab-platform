# 도시 재가동 · SKY RUN

실행: `/run/quiz-rally` · 직접 경로: `/labs/quiz-rally/index.html`

새 게임은 기본 15분으로 운영하며, 점수 없이 결승선 도착순으로 경쟁하는 직접 조작형 2D 장애물 레이스입니다. 입체감 있는 코스와 자유 이동, 점프, 다이빙을 사용합니다. 교사마다 별도 코드와 문제 복사본을 가지며, 최대 40명이 한 경기에 참여합니다. 기본 중2 「물질의 구성」 문제 또는 다른 단원·과목의 파일을 사용합니다.

## 학생 흐름

1. 로봇의 머리·가슴·배·등 장비와 색을 골라 입장합니다.
2. 3초 카운트다운 후 WASD/방향키로 이동합니다. Space는 점프, Shift는 다이빙입니다. 자동 전진·점수는 없습니다. 에너지는 100에서 초당 4씩 줄며, 지상 이동 속도는 에너지에 따라 100%에서 최저 35%까지 서서히 낮아집니다.
3. 코스의 노란 `?` 상자를 가까이 지나면 문제 팝업이 열립니다. 자기 로봇은 멈추고 보호되며 에너지 소모도 멈춥니다. 다른 학생들은 계속 달립니다. 상자는 학생별로 독립적으로 획득합니다.
4. 정답을 맞히면 에너지를 45 충전하며 최대 100을 유지합니다. 가방에 빈칸이 있으면 경기 아이템 6종을 무작위 순서로 한 번씩 지급한 뒤 다시 섞습니다. 빈칸에 아이템 1개를 확정 지급합니다. 가방 3칸이 가득 차도 문제를 풀 수 있고, 기존 아이템을 유지한 채 에너지만 충전합니다. 보기 선택은 즉시 표시하고, 서버의 정답 확인 후 팝업을 닫아 바로 조작할 수 있습니다. 별도 보상 선택 화면은 없습니다.
5. 오답은 1초 뒤 다른 보기를 선택해 재도전합니다. 점수 차감은 없습니다. 정답·해설만 확인하면 아이템은 받지 않습니다. 팝업은 언제든 닫고 경기로 돌아갈 수 있습니다.
6. 1·2·3키 또는 슬롯 클릭으로 아이템을 선택하고 F 또는 사용 버튼으로 사용합니다. 문제를 끝내지 않고 닫으면 다음 상자에서 이어 풀며, 끝낸 문제는 다음 문제로 바뀝니다. 문제 은행은 섞어서 순환합니다.
7. 최종 결승선을 통과하면 순위가 확정되고 친구를 관전합니다. 전체 경기는 제한 시간 또는 교사 종료로 끝납니다. 문제를 모두 맞혀야 완주하는 조건은 없습니다.

## 코스와 판정

- 하나의 도시를 출발 광장 → 네온 골목 → 풍력 지붕 → 프레스 공장 → 회전 타워 → 붕괴 스카이웨이 → 시티 코어 순서로 횡단합니다. 한 바퀴를 반복하지 않고 하나의 결승선까지 이어집니다. 구역마다 지형과 장애물 배치가 다릅니다.
- 기본 15분 경기의 길이는 27,000 좌표 단위입니다. 이전 20회 반복·94,000 단위에서 약 71% 줄였습니다. 5·8·10분 선택 시 14,000·17,900·20,500으로 조절됩니다. 15분은 제한 시간이며 완주 시간 보장은 아닙니다. 기본 속도는 초당 175이며 앞·뒤·좌·우 및 대각선 이동을 지원하고 대각선 속도를 정규화합니다.
- 폭이 좁고 빠르게 움직이는 문, 번갈아 막힌 벽, 바람이 부는 좁은 지붕, 반대 방향 컨베이어, 경고 후 내려치는 프레스, 교차 회전봉, 굴러오는 공과 붕괴 발판을 배치합니다. 낮은 벽과 끊어진 길은 점프하고 높은 벽은 돌아갑니다. 붕괴 발판에는 항상 안전한 경로가 남습니다. 장애물 판정과 그림은 같은 데이터를 사용합니다.
- 문제 상자는 일정한 줄 대신 서로 다른 좌우 위치와 간격에 놓입니다. 방별로 배치가 달라지며 같은 방의 학생들은 동일한 위치를 봅니다. 새 코스는 기존보다 약 두 배의 상자를 제공하며 낭떠러지·프레스·회전봉 등의 위험한 위치를 피합니다. 문제 은행과 상자 개수는 별개입니다.
- 카운트다운·문제 풀이·교사 일시 정지·완주 후에는 에너지를 소모하지 않습니다. 에너지 감소는 평지 점프와 질주에도 적용합니다. 필수 낭떠러지를 넘는 점프에만 최소 78%의 이동 보조를 적용해 배터리가 비어도 길을 건널 수 있습니다.
- 낙하 시 0.85초 뒤 직전 체크포인트로 돌아옵니다. 목숨 소진·영구 탈락은 없습니다. 로봇 크기는 구역에 따라 커지지 않습니다.
- 구역별 하늘·배경 도시·구름, 입체 바닥 가장자리와 조명, 깃발, 건물·나무·태양광 패널·공장 설비를 표시합니다. 장식은 충돌 판정에 영향을 주지 않습니다. 구역 진입 배너와 실제 학급 친구들의 로봇·위치·순위를 표시합니다. 가상 경쟁 봇은 없습니다.
- 서버와 브라우저가 같은 물리 모형을 사용합니다. 방향 전환·점프·키 놓기를 시각과 순서 번호로 기록해 묶어서 전송하고, 서버가 확인한 입력만 지웁니다. 늦은 응답은 아직 확인되지 않은 입력을 다시 적용한 현재 위치로 보정합니다. 서버는 마지막 입력 시점을 저장하고, 그 뒤의 예상 이동은 화면·순위 판정에서 계산합니다. 아직 도착하지 않은 방향 전환이나 점프를 서버 요청 시각으로 밀어내지 않습니다. 아이템·문제 팝업 동작도 같은 입력 시각을 사용하며 사용 간격과 정답 검증은 서버 시계로 검사합니다. 실행 중인 게임 시계는 응답에 맞춰 건너뛰지 않고 최대 ±2%로 점진 조정합니다. 편도 지연을 왕복 시간의 절반으로 가정하지 않습니다. 카메라는 로봇 발밑의 세로 화면 위치를 고정해 뒤늦은 추적으로 생기는 흔들림을 없앱니다. 렌더링은 브라우저의 화면 갱신 주기에 맞추며 점프 높이는 프레임 수에 영향을 받지 않습니다. 서버는 좌표 입력을 신뢰하지 않으며 조작값·순서·시간 범위를 검증합니다. 서버에서 입력은 2.2초 뒤 만료됩니다. 브라우저는 6초 이상 응답이 없을 때 한 번 조작을 멈추고 연결 확인 상태를 표시합니다.
- 결승선 통과 시각을 보간해 모든 완주자의 1·2·3…등을 확정합니다. 요청 도착 순서에 의존하지 않습니다. 정확히 같은 통과 시각은 학생 ID로 안정적으로 정렬합니다. 완주 보너스는 없습니다.
- 미완주자는 종료 시 위치로 표시합니다. 정답·도전 수는 학습 기록이며 등수를 바꾸지 않습니다.

## 아이템

| 아이템 | 효과 |
|---|---|
| 폭탄 | 뒤에 설치, 0.5초 뒤 활성화. 밟으면 밀려나고 0.85초 조작 불가. 최대 14초 유지 |
| 미사일 | 좌우·뒤 이동과 관계없이 코스 앞쪽으로 직선 발사. 선택 시 조준선 표시, 맞으면 밀려나고 0.85초 조작 불가. 높은 점프로 회피 가능 |
| 바나나 | 뒤에 놓으며 밟으면 1.05초 동안 미끄러지며 조작할 수 없습니다. 최대 14초 유지 |
| 감속 영역 | 사용 위치 주변에 5초 동안 영역 생성, 다른 로봇 속도 38% |
| 보호막 | 4초 동안 아이템 공격·감속을 방어 |
| 질주 | 3초 동안 이동 속도 2배 |

감속 영역은 반경과 일치하는 반투명 바닥 효과·회전 고리·부유 코어로 표시합니다. 보호막은 청록색 반투명 돔·육각 격자·남은 시간 테두리로 표시합니다. 미사일의 몸체·불꽃·궤적 방향은 실제 비행 방향과 같습니다. 가방은 전용 벡터 아이콘을 사용합니다.

자기 공격에 자신이 맞지 않습니다. 폭탄·바나나·미사일은 한 명에게만 소비됩니다. 아이템 사용 간격은 0.9초입니다. 교사가 방해 아이템을 끄면 보호막·질주를 섞어서 한 번씩 지급합니다. 가방이 가득 찬 상태의 정답은 아이템 지급 순서를 소비하지 않습니다. 문제 풀이 중·완주 후에는 아이템을 사용할 수 없습니다.

## 화면과 교사 운영

학생 화면은 큰 경기장과 작은 순위·시간·에너지·아이템 표시로 구성합니다. 문제는 별도 팝업이며 그림 확대를 지원합니다. 휴대전화에는 조이스틱·점프·다이빙 버튼이 나타납니다. 전체 화면 버튼도 제공합니다. 교사는 순위 목록에서 관전할 친구를 고르고 일시 정지·재개·종료할 수 있습니다. 일시 정지는 경기 시간과 물리를 함께 멈춥니다.

학생은 별도 계정 없이 참여 코드와 닉네임을 사용합니다. 교사 접근 키는 학생에게 공유하지 않습니다. 결과는 14일간 재조회하며 CSV에 도착 등수·완주 여부·진행률·정답·도전·낙하 횟수를 담습니다. 학생은 종료 후 오답 해설 최대 6개를 확인합니다.

## 문제 가져오기와 교육 범위

엑셀 첫 시트 또는 CSV의 4지선다 문제를 1~500개, 파일당 3MB까지 가져옵니다. 엑셀 삽입 그림은 왼쪽 위를 해당 문제 행에 맞춥니다. 문제당 그림 1개, 1MB 이하이며 그림 URL도 사용할 수 있습니다. 단원 선택, 미리보기, 양식 다운로드를 유지합니다. 다른 반의 문제·그림·정답·접근 키는 공유하지 않습니다.

기본 24문제: 원소·원자·분자, 원자핵과 전자, 양성자·중성자·전자, 전하와 중성, 원자 번호, 이온, 원소 기호와 분자식. 선택 확장 4문제: 주기율표의 족·주기와 원자 번호 배열. 전자껍질은 포함하지 않습니다. 게임은 특정 학습지에 종속되지 않습니다.

## 구현 및 검증

새 방에 `arena.version=2`, `energy=true`, `supplies=2`를 저장합니다. 에너지와 늘어난 상자 배치도 새 방부터 적용합니다. 기존 반복 코스(version 1), 에너지 레이스 방과 이전 퀴즈 방은 기존 규칙을 유지하므로 새 도시 코스를 사용하려면 새 방을 만듭니다. 데이터베이스 스키마 변경은 없습니다. 학생별 버전과 방 메타 버전으로 조작·정답·교사 제어의 충돌을 검사합니다. 아이템은 해당 요청에서 추가한 효과와 피격 기록만 현재 데이터에 합쳐 저장하므로 다른 학생의 아이템을 덮어쓰지 않습니다. 개별 아이템의 피격자 조건과 전체 아이템 수 제한도 같은 갱신에서 검사합니다. 결승 순위 확정은 아이템 버전을 함께 확인합니다.

물리 원본은 `lib/quiz-rally-arena.ts`, 도시 지형은 `lib/quiz-rally-city.ts`입니다. 수정 후 `node scripts/build-quiz-arena.cjs`로 `public/labs/quiz-rally/arena-model.js`를 생성합니다. UI는 `arena.js`, `arena.css`, 벡터 효과는 `arena-fx.js`, 도시 배경과 장식은 `arena-scene.js`에 있고 기존 앱의 입장·문제 가져오기·로봇 꾸미기를 연결합니다.

검증 명령: `node --test tests/quiz-rally-learning.test.cjs tests/quiz-rally-arena.test.cjs tests/quiz-rally-concurrency.test.cjs tests/quiz-rally-course.test.cjs tests/quiz-rally.test.cjs tests/quiz-rally-import.test.cjs tests/quiz-rally-journey.test.cjs`.

물리·점프·낙하·아이템·팝업 보호·정답 보상·중복 처리·서버 조작 검증·방별 격리·30명 동시 조작과 완주 순위·일시 정지·기존 방 호환성을 검사합니다. 실제 30~40대 교실 무선망 부하는 별도 검증 대상입니다. 웹소켓 게임 서버가 아닌 서버 상태 갱신과 클라이언트 예측 방식이므로 네트워크 지연에 따라 상대 위치 보정이 보일 수 있습니다.
