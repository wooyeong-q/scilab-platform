# 도시 재가동 · 에너지 레이스

실행: `/run/quiz-rally` · 직접 경로: `/labs/quiz-rally/index.html`

새 게임방은 문제 캡슐을 획득하며 도시 코스를 달리는 학급 레이스입니다. 기본 문제는 중2 「물질의 구성」 24개이며 주기율표 확장 4개를 선택할 수 있습니다. 다른 단원·과목의 엑셀·CSV 문제도 사용합니다. 반마다 별도의 코드와 문제 복사본을 가지며, 서로 모르는 교사들이 독립적으로 최대 40명씩 운영할 수 있습니다.

## 학생의 흐름

1. 머리·가슴·배·등 장비와 색을 골라 로봇을 만들고 참여합니다.
2. 교사가 시작하면 자동으로 전진합니다. 방향키, A/D 또는 화면의 5개 차선 버튼으로 이동합니다.
3. 같은 차선의 가까운 `?` 캡슐을 지나면 문제가 열립니다. 캡슐은 학생마다 따로 획득하므로 다른 학생이 빼앗지 않습니다.
4. 정답이면 즉시 에너지 +45(최대 100), 점수 +100을 받습니다. 30% 확률로 아이템 1개도 자동 지급합니다. 매번 상자를 선택할 필요가 없습니다.
5. 오답 뒤에는 다른 보기를 바로 고릅니다. 첫 오답에는 차감이 없고, 같은 문제에 다시 답할 때마다 −20점입니다. 정답과 해설은 정답을 맞히거나 ‘정답·해설 보기’를 눌렀을 때 공개합니다. 해설만 보면 충전되지 않습니다.
6. 해설을 확인한 뒤 코스로 돌아갑니다. 다음 캡슐에서 다음 문제가 열립니다. 풀지 않은 채 닫은 문제는 다음 캡슐에서 이어 풀고, 정답 또는 해설 확인이 끝난 문제는 다음 문제로 바뀝니다. 문제 은행을 모두 사용하면 순서를 섞어 다시 사용합니다.
7. 최종 결승선까지 실제 이동하면 완주합니다. 모든 문제를 맞혀야 완주하는 조건은 없습니다. 먼저 완주한 학생은 친구들의 진행을 확인하며 기다립니다. 전체 게임은 제한 시간 또는 교사의 종료로 끝납니다.

## 에너지와 경주

- 시작 에너지 70, 초당 1.8 감소. 속도는 에너지에 비례하며 18~72m/s입니다. 0에서도 18m/s로 계속 움직입니다.
- 문제 풀이 중에도 주행과 에너지 감소가 이어집니다. 주황색 장애물에 닿으면 에너지 18을 잃습니다. 기존 방어막은 점수 가져오기 방어용입니다.
- 문제 캡슐은 260m 간격으로 차선을 바꾸며 등장합니다. 장애물은 480m 간격입니다. 로봇 크기는 구역 진입이나 에너지에 따라 증가하지 않습니다.
- 코스 길이는 `max(2400, min(문제 수 × 650, 제한 시간(초) × 38))`m입니다. 문제 수가 많은 파일도 제한 시간 안에 경주할 수 있습니다.
- 최종 1·2·3등은 보너스를 한 번 받습니다. 기준 문제 수는 `min(문제 수, ceil(코스 길이/650))`; 기본 점수(×100)의 20%·12%·8%를 지급합니다. 500문항을 올려도 완주 보너스가 과도하게 커지지 않습니다. 기본 24문제/8분은 +480/+288/+192점입니다.
- 물리적 통과 시각순으로 판정합니다. 폴링이나 요청 도착순이 아닙니다. 같은 계산 시각인 경우 학생 ID를 안정적인 동점 기준으로 사용합니다. 첫 3명과 보너스는 원자적으로 확정하고 중복 요청·재접속 시 다시 지급하지 않습니다.
- 이동 순위와 최종 점수 순위는 별도입니다. 아이템이 이동 거리를 직접 바꾸지 않습니다.

## 아이템

- 점수 2배: 다음 정답 +200점. 틀려도 효과가 유지됩니다.
- 보기 줄이기: 열린 문제의 오답 보기 2개를 지웁니다. 최초 1개 제공합니다.
- 점수 가져오기: 자신보다 점수가 높은 미완주 학생에게서 50~150점을 10점 단위로 무작위 선택해 가져옵니다. 대상의 잔액까지만 가져오며 성공 후 30초간 보호합니다.
- 방어막: 다음 점수 가져오기를 한 번 막습니다.

아이템은 종류별 최대 3개, 넘치면 +40점입니다. 교사가 점수 가져오기를 끄면 방어막과 점수 가져오기는 보상에서 제외됩니다. 완주 후 아이템 사용과 완주자 대상 점수 가져오기는 중단됩니다.

## 화면과 운영

큰 도시 코스, 에너지 막대, 속도, 남은 거리, 가까운 문제 캡슐의 차선을 표시합니다. 여섯 구역을 지날수록 건물 높이와 빛이 달라지고 구역 진입 배너가 나타납니다. ‘코스 크게’와 전체 화면을 제공합니다. 학생이 문제를 얻으면 옆에 문제와 그림이 열리며, 작은 화면에서는 문제로 자동 이동합니다. 그림 확대도 유지합니다.

교사 화면은 이동 거리순으로 전원을 보여 주고 선택한 친구의 코스를 관전합니다. 학생도 학급 전체 진행을 확인합니다. 실제 서버의 위치 기준값으로 주행을 부드럽게 보간하고 약 1.1~1.6초마다 현황을 갱신합니다. 인위적인 경쟁 봇은 없습니다. 일시 정지는 타이머·주행·에너지 감소를 함께 멈춥니다. 늦게 참여한 학생은 출발선에서 시작합니다.

별도 학생 계정 없이 닉네임과 기기별 참여 정보로 접속합니다. 교사 접근 키는 학생에게 공유하지 않습니다. 14일간 결과 재조회, 종료 후 CSV 저장, 학생의 오답 해설 최대 6개를 지원합니다. 게임 점수와 정답률은 별도로 표시합니다.

## 문제 가져오기와 교육 범위

엑셀 첫 시트 또는 CSV의 4지선다 문제를 1~500개, 파일당 3MB까지 가져옵니다. 엑셀 그림은 셀 위에 삽입하고 왼쪽 위를 해당 문제 행에 맞춥니다. 문제당 그림 1개, 1MB 이하. 그림 URL, 단원 선택, 업로드 전 미리보기와 양식 다운로드를 지원합니다. 방별 문제·그림이 분리되고 다른 학생에게 정답 키·응답·접근 토큰을 공개하지 않습니다.

기본 문제: 원소·원자·분자, 원자핵과 전자, 양성자·중성자·전자, 전하와 중성, 원자 번호, 이온, 원소 기호와 분자식. 선택 확장: 주기율표의 족·주기와 원자 번호 배열. 전자껍질은 포함하지 않습니다. 원자 모형은 실제 크기 비율이 아니며, 물을 물 원자 또는 금을 금 분자로 표현하지 않습니다. 흔한 수소 원자핵에는 중성자가 없다는 예외를 해설에 포함합니다.

## 호환성과 검증

기존 방에 `course` 값이 없으면 기존 문제 수 기반 경주·상자 보상 규칙을 유지합니다. 새 방부터 에너지 레이스가 적용됩니다. 데이터베이스 스키마 변경은 없습니다. JSONB의 학생별 버전 조건으로 수정하며 다른 반이나 학생의 상태를 덮어쓰지 않습니다.

물리는 `lib/quiz-rally-course.ts`에서 관리합니다. 수정 후 `node scripts/build-quiz-course.cjs`로 브라우저의 `course-model.js`를 생성합니다.

검증: `node --test tests/quiz-rally-course.test.cjs tests/quiz-rally.test.cjs tests/quiz-rally-import.test.cjs tests/quiz-rally-journey.test.cjs`. 30명 동시 차선 변경·도착 처리, 통과 시각 순위, 중복 보상 방지, 최저 속도, 충돌 1회 처리, 충전, 재도전, 문제 순환, 일시 정지·조기 종료, 늦은 입장, 엑셀 그림, 방별 격리와 기존 방 호환성을 확인합니다.

미니게임은 이번 변경에 포함하지 않았습니다. 실제 30~40대의 교실 무선망에서의 부하 검증은 별도로 필요합니다.
