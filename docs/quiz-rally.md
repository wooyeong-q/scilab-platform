# 도시 재가동

경로: `/labs/quiz-rally/index.html` · 플랫폼 실행 경로: `/run/quiz-rally`

대정전으로 멈춘 도시를 문제 풀이로 복구하는 학급 게임입니다. 기본 중2 「물질의 구성」 문제 또는 교사가 올린 다른 단원·과목의 문제로 진행합니다. 교사가 방을 만들고 학생은 자기 기기에서 코드와 닉네임으로 참여합니다. 서로 모르는 교사와 여러 반이 같은 서비스에서 방을 독립적으로 운영합니다.

## 수업 진행

1. 교사 탭에서 방 이름과 5·8·10·15분을 선택합니다. 기본 문제는 24개이며 족·주기 등 주기율표 확장 4개를 선택할 수 있습니다.
2. 학생 참여 링크를 공유하거나 6자리 코드를 전달합니다. 최대 40명까지 참여합니다. 학생별 기기 1대가 필요합니다.
3. 학생이 들어오면 시작합니다. 학생은 각자 무작위 순서로 문제를 풀고 정답마다 100점을 얻습니다. 오답 뒤에는 남은 보기를 바로 선택할 수 있습니다. 같은 문제에 다시 답하는 순간마다 20점을 차감하며 점수는 음수가 될 수 있습니다. 정답은 숨겨 두고, ‘정답·해설 보기’를 선택하면 정답을 공개하며 해당 문제의 재도전을 끝냅니다. 재도전에도 정답 보상은 한 번만 받습니다. 첫 오답만 고르거나 해설을 보는 것은 재도전 차감에 포함하지 않습니다.
4. 정답 뒤 상자 3개 중 1개를 골라 보너스 40·70점 또는 아이템을 받습니다. 한 종류당 최대 3개를 보관하며 초과 보상은 40점으로 전환합니다.
5. 교사 화면에서 시간과 순위를 크게 보여 줍니다. 전체 화면, 일시 정지·재개, 조기 종료, 참여 종료를 지원합니다.
6. 종료 후 정답 수·도전 수·정답률과 게임 점수를 따로 확인하고 CSV로 저장합니다. 학생 화면에는 틀린 개념의 해설이 최대 6개 나타납니다. 게임 점수는 성적으로 사용하지 않습니다.

## 아이템

- 점수 2배: 다음 정답이 200점. 틀려도 준비 효과가 남습니다.
- 보기 줄이기: 현재 문제의 오답 보기 2개를 지웁니다. 첫 참여 시 1개를 제공합니다.
- 점수 가져오기: 자신보다 점수가 높은 친구에게서 30점. 성공한 대상은 30초간 다시 가져올 수 없습니다.
- 방어막: 다음 점수 가져오기를 1번 막습니다. 공격·방어 아이템이 각각 소모됩니다.

교사가 점수 가져오기를 끄면 점수 가져오기와 방어막은 보상과 가방에서 제외됩니다.

## 교육 범위와 표현

기본 24문제: 원자 내부·입자의 전하·양성자 수와 원소·원자 번호·중성·분자와 원자·원소 기호·간단한 분자식·이온. 확장 4문제: 족·주기·같은 족의 성질·원자 번호에 따른 배열. 전자껍질은 포함하지 않습니다. 원자 내부 모형은 실제 크기·위치 비율이 아니며, 금을 독립된 금 분자로 표현하지 않습니다. 가장 흔한 수소 원자핵에는 중성자가 없다는 예외를 해설에 포함합니다.

사실 확인에 참고한 1차 자료:
- Royal Society of Chemistry, Oxygen: https://periodic-table.rsc.org/element/8/oxygen
- Royal Society of Chemistry, Sodium: https://periodic-table.rsc.org/element/11/sodium

## 구현 및 운영

- 정적 화면: `public/labs/quiz-rally/`
- 서버 문제은행: `lib/quiz-rally-questions.ts` (정답 키는 클라이언트에 배포하지 않음)
- 게임·권한·저장: `lib/quiz-rally.ts`, `lib/quiz-rally-http.ts`
- API: `app/api/labs/quiz-rally/sessions/` 및 `[code]/`
- 저장: Neon PostgreSQL `quiz_rally_sessions`. 새 테이블·인덱스는 배포 시 가산 마이그레이션만 수행합니다. 요청 중 DDL은 실행하지 않습니다.
- 각 방의 무작위 교사 키, 각 학생의 무작위 토큰을 서버에서 해시 검증합니다. 학생 공유 URL에는 교사 키를 포함하지 않습니다.
- 점수와 아이템은 서버에서 판정합니다. 버전 조건과 JSONB 경로 갱신으로 동시 요청 시 다른 학생의 상태를 덮어쓰지 않습니다. 점수 가져오기는 두 학생의 점수를 한 SQL 문으로 갱신합니다.
- 중복 요청 ID, 현재 문제 nonce, 답변·보상 상태를 검증해 재시도·더블 클릭의 중복 보상을 방지합니다.
- 교사 약 3.5초, 학생 약 5초 간격으로 작은 상태 응답만 갱신합니다. 도시·친구 확대 화면은 약 3.5초 간격으로 갱신합니다. 숨긴 탭은 중지하고 오류 시 간격을 늘립니다. 학생 동작 시에는 당사자와 필요한 대상의 저장 상태만 읽습니다.
- 종료·시간 초과·일시 정지는 서버에서도 검증합니다. 늦게 도착한 답으로 점수를 얻지 못합니다.
- 학생과 교사 접근 정보는 해당 기기의 localStorage에 저장됩니다. 창을 새로 열면 같은 기기로 복귀할 수 있습니다. 브라우저 저장 정보를 삭제하거나 다른 기기로 옮기면 접근을 자동 복구할 수 없습니다.
- 방은 생성 후 14일 동안 접근할 수 있습니다. 자동 데이터 삭제 기능을 뜻하지는 않습니다. 중요한 결과는 교사가 CSV로 저장합니다.

## 확인

`node --test tests/quiz-rally.test.cjs`는 PGlite의 PostgreSQL 엔진에서 SQL을 실행하여 동시 30명 참여·답변, 권한·반별 분리, 중복 요청, 힌트·2배·점수 가져오기·방어막, 시간·일시 정지·종료, 오류 응답을 검증합니다. 로컬 브라우저에서도 서로 다른 교사/학생 브라우저를 사용해 참여→문제→상자→아이템→새로고침→정지/재개→30명 순위→종료→CSV 흐름을 확인했습니다. 360~1920px 화면을 확인했습니다.

## 내 문제와 그림 업로드

‘교사 · 게임 만들기 → 내 문제 파일’에서 양식을 받아 수정하고 올립니다. 첫 시트의 필수 열은 문제, 보기1~4, 정답(1~4)입니다. 해설·단원·문제그림·그림설명은 선택입니다. 파일은 .xlsx/.csv, 최대 500문제·3MB입니다. .xls는 .xlsx로 다시 저장합니다. 해설이 없으면 정답 문구를 사용합니다.

엑셀의 일반 삽입 그림(oneCellAnchor/twoCellAnchor)을 문제 행과 연결합니다. 그림은 ‘셀 위에 배치’로 넣고 왼쪽 위를 해당 문제 행에 맞춥니다. 문제당 1장, PNG/JPG/WebP, 그림당 1MB 이하입니다. 셀 내부 그림 형식은 안내 후 거부합니다. CSV는 삽입 그림을 보관할 수 없고 https 그림 URL을 사용할 수 있습니다. 외부 URL 그림은 학생 브라우저가 직접 불러오므로 접근 가능한 주소여야 합니다. 서버가 외부 URL을 대신 가져오지 않습니다.

교사는 문제·정답·그림 미리보기와 단원 필터를 확인하고 게임을 만듭니다. 생성 시 검증된 문제와 그림을 방별 복사본으로 고정합니다. 새 업로드는 기존 방이나 다른 교사의 방에 영향을 주지 않습니다. 문제 은행과 그림은 상태 JSON과 별도 열로 저장하고, 학생에게는 현재 문제와 불투명 그림 경로만 전달합니다. 압축 해제 용량과 XML 외부 엔터티를 제한합니다. 전체 그림 2.5MB, 검증된 문제 데이터 4.2MB를 넘으면 파일 분할을 안내합니다.

## 도시 스토리

도시는 주거 거리·상점가·강변 공원·항구·연구 지구·하늘 정원의 테마를 가진 번호 구역으로 이어집니다. 정답 1개마다 한 칸 이동하며 10칸을 이동할 때마다 다음 구역으로 넘어갑니다. 예를 들어 23개 정답은 3구역의 세 번째 칸, 500개 정답은 51구역의 출발 지점입니다. 테마는 순환하지만 구역 번호와 누적 이동은 계속 증가합니다. 6곳 복구 후 완료라는 표현을 없애고, 게임 종료는 기존 제한 시간 또는 교사의 종료로 결정합니다. 기존 방의 cityTarget 값은 호환성을 위해 저장되어 있어도 이동과 화면 종료에 사용하지 않습니다.

위에서 비스듬히 내려다보는 입체 도시와 기존 로봇 모형 크기를 유지합니다. 도시와 문제는 각각 화면 공간을 차지해 관제 창이 이동 경로를 가리지 않습니다. 작은 화면에서는 도시와 문제를 세로로 배치합니다. 같은 구역에서는 캐릭터 DOM을 유지해 부드럽게 이동하며, 구역 경계를 넘으면 새로운 거리로 전환합니다. 동작 줄이기 설정을 지원합니다.

정답 요청은 상태 조회와 원자적 갱신의 두 번의 DB 왕복으로 처리합니다. UPDATE RETURNING에서 저장된 현재 문제와 순위를 반환하여 별도 재조회를 생략합니다. 엑셀 해석 모듈은 일반 답변 처리 경로에서 제외했습니다. 선택 즉시 ‘답을 확인하고 있어요’를 표시하며 실제 판정 전 정답을 추측해서 표시하지 않습니다. 응답 Server-Timing과 1초를 넘긴 요청의 익명 지연 로그로 운영 시간을 측정할 수 있습니다. 오답마다 nonce를 바꾸고 중복 요청 ID를 확인해 동시 재선택의 중복 차감을 막습니다.

학생 계정, 학기 단위 누적 성적과 팀전은 포함하지 않습니다. 업로드 문제는 현재 4지선다형이며 모두 풀면 문제 순서와 보기 순서를 바꾸어 반복합니다.

추가 검증: `node --test tests/quiz-rally-import.test.cjs`는 실제 양식의 셀/삽입 그림, CSV 줄바꿈, 500문항 경계, 파일·압축 제한, 오답 정답 숨김, 중복 재도전의 단일 차감, 새 nonce, 반별 은행·그림 분리와 종료 복습을 검증합니다.

## 학생 캐릭터와 친구들의 진행 상황

학생은 참여할 때 머리·가슴·배·등 장비를 조합해 복구 로봇을 꾸밉니다. 각 부위의 색도 독립적으로 고릅니다. 선택은 방별 학생 정보에 저장되고 재접속해도 유지됩니다. 캐릭터 정보가 없는 기존 방에도 학생 ID에 따라 일정한 기본 캐릭터가 표시됩니다. 캐릭터에 따른 점수나 능력 차이는 없습니다.

이동 위치와 이동 순위는 서버가 확정한 정답 수만 사용합니다. 보너스·차감·아이템 점수는 이동에 영향을 주지 않습니다. 최종 순위는 기존 점수 규칙을 유지하며, 두 기준을 화면에 명시합니다. 같은 칸은 공동 순위이고 바로 앞·뒤 친구의 이름과 칸 차이를 보여줍니다. 내 정답 수가 증가하면서 기존 친구의 현재 위치를 실제로 넘어설 때만 추월 알림을 띄웁니다. 단순 동점 도달, 새 참여자, 퇴장, 점수 변화, 최초 접속과 오래 끊긴 뒤의 재접속은 추월로 표시하지 않습니다.

지도는 현재 학생의 구역을, 교사 화면은 선두의 구역을 보여줍니다. 같은 칸에는 로봇 2명과 추가 인원을 표시합니다. 내 로봇과 선택한 친구를 우선 표시합니다. ‘우리 반 현황’은 최대 40명 전원을 이동 순위로 표시하며 각 학생의 구역·이동 수·점수·활동을 확인할 수 있습니다. 전체 구역 버튼이나 친구 카드를 눌러 멀리 떨어진 구역도 탐색합니다. 빈 구역 수백 개를 만들지 않고 실제 참가자가 있는 구역과 선택한 구역을 표시합니다.

진행 정보는 기존 방별 인증 응답에서 계산하며 추가 API 호출이나 데이터베이스 저장을 만들지 않습니다. 다른 학생의 문제·답·선택·접근 키는 공개하지 않습니다. 기존 정답 요청의 두 번의 DB 왕복과 방별 격리를 유지합니다. `tests/quiz-rally-journey.test.cjs`는 장거리 진행·공동 순위·가까운 경쟁자·실제 추월·재접속 등을 검증합니다.

## 부위별 로봇 꾸미기

머리 12종, 가슴·배·등 장비 각 8종으로 총 36종의 부품을 제공합니다. 기존 부품 번호는 유지하고 다음 18종을 추가했습니다.

- 머리: 냄비 요리사, 달걀 프라이, 꽥꽥 오리, 안테나 TV, 고양이 헬멧, UFO 접시
- 가슴: 토스터, 알람시계, 멜빵 작업복, 하트 엔진
- 배: 세탁기, 간식 자판기, 수박 배, 피자 오븐
- 등 장비: 선풍기, 둥둥 풍선, 비상 우산, 나비 날개

각 부위별로 노랑·민트·보라·코랄·초록·파랑을 고를 수 있습니다. 머리/가슴/배/등 탭, 부품 확대 썸네일, 전체 미리보기, 모든 부품 섞기를 제공합니다. 새 부품도 각 부위에서 직접 골라 조합할 수 있습니다. 부품 목록만 스크롤해 모바일에서도 미리보기와 색깔, 저장 버튼을 쉽게 찾도록 했습니다. 미리보기에서는 선풍기·세탁기·하트·풍선·냄비 김이 움직이며, 동작 줄이기 설정을 따릅니다. 기본 조합으로 바로 참여할 수도 있습니다.

참여 전에는 미리보기의 조합을 게임 참여와 함께 저장합니다. 대기 화면과 게임 화면의 ‘로봇 꾸미기’에서는 저장/취소를 지원합니다. 편집 중 다른 학생의 진행 정보가 갱신돼도 저장 전 선택은 유지됩니다. 저장한 조합은 대기실, 도시, 학생 점수, 교사 순위와 친구 현황에 같은 렌더러로 표시합니다. 다른 게임에 참여할 때도 마지막 저장 조합을 기본값으로 사용합니다.

`robot`은 선택 번호 8개만 포함하는 검증된 객체입니다. 기존 `avatar`만 저장된 학생은 기존 종류를 바탕으로 기본 조합을 받습니다. `customize`는 자신의 캐릭터만 바꾸며 대기·진행·일시 정지 때 허용합니다. 종료 후 변경은 거부합니다. 점수·인벤토리·문제·nonce는 그대로 두고 기존 버전 조건과 원자적 저장으로 정답 제출과 동시 실행해도 서로 덮어쓰지 않습니다. 서버 검증은 잘못된 부품, 재접속, 학생 간 동일 표시, 권한, 대기/일시 정지/종료, 정답과 꾸미기 동시 저장 및 두 번의 DB 왕복을 확인합니다.
