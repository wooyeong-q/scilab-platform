# 도시 재가동 · SKY RUN

실행: `/run/quiz-rally` · 직접 경로: `/labs/quiz-rally/index.html`

새 게임은 점수 없이 결승선 도착순으로 경쟁하는 직접 조작형 2D 장애물 레이스입니다. 입체감 있는 코스와 자유 이동, 점프, 다이빙을 사용합니다. 교사마다 별도 코드와 문제 복사본을 가지며, 최대 40명이 한 경기에 참여합니다. 기본 중2 「물질의 구성」 문제 또는 다른 단원·과목의 파일을 사용합니다.

## 학생 흐름

1. 로봇의 머리·가슴·배·등 장비와 색을 골라 입장합니다.
2. 3초 카운트다운 후 WASD/방향키로 이동합니다. Space는 점프, Shift는 다이빙입니다. 자동 전진·에너지·점수는 없습니다.
3. 코스의 노란 `?` 상자를 가까이 지나면 문제 팝업이 열립니다. 자기 로봇은 멈추고 보호되며, 다른 학생들은 계속 달립니다. 상자는 학생별로 독립적으로 획득합니다.
4. 정답을 맞히면 무작위 경기 아이템 1개를 확정 지급합니다. 가방은 총 3칸입니다. 매 정답마다 별도 보상 선택 화면을 거치지 않습니다.
5. 오답은 1초 뒤 다른 보기를 선택해 재도전합니다. 점수 차감은 없습니다. 정답·해설만 확인하면 아이템은 받지 않습니다. 팝업은 언제든 닫고 경기로 돌아갈 수 있습니다.
6. 1·2·3키 또는 슬롯 클릭으로 아이템을 선택하고 F 또는 사용 버튼으로 사용합니다. 문제를 끝내지 않고 닫으면 다음 상자에서 이어 풀며, 끝낸 문제는 다음 문제로 바뀝니다. 문제 은행은 섞어서 순환합니다.
7. 최종 결승선을 통과하면 순위가 확정되고 친구를 관전합니다. 전체 경기는 제한 시간 또는 교사 종료로 끝납니다. 문제를 모두 맞혀야 완주하는 조건은 없습니다.

## 코스와 판정

- 7구역: 출발 광장, 움직이는 문, 회전봉 정원, 점프 브리지, 컨베이어 길, 볼링 대로, 사라지는 발판.
- 코스 길이 4,700 좌표 단위, 기본 속도 초당 145. 자유로운 앞·뒤·좌·우와 대각선 이동이며 대각선 속도를 정규화합니다.
- 움직이는 문은 열린 틈을 찾아 통과합니다. 회전봉·범퍼·굴러오는 공은 부딪히면 튕겨 나갑니다. 끊어진 발판은 점프하고, 컨베이어는 옆으로 밀며, 일부 발판은 경고 후 잠시 사라집니다.
- 낙하 시 0.85초 뒤 직전 체크포인트로 돌아옵니다. 목숨 소진·영구 탈락은 없습니다. 로봇 크기는 구역에 따라 커지지 않습니다.
- 구역 진입 배너, 색이 바뀌는 코스, 실제 학급 친구들의 로봇·위치·순위를 표시합니다. 가상 경쟁 봇은 없습니다.
- 서버와 브라우저가 같은 물리 모형을 사용합니다. 이동은 즉시 화면에서 예측하고 서버 상태로 보정합니다. 서버는 좌표 입력을 신뢰하지 않으며 조작값·순서·시간 범위를 검증합니다. 연결이 끊기면 입력은 2.2초 뒤 만료됩니다.
- 결승선 통과 시각을 보간해 모든 완주자의 1·2·3…등을 확정합니다. 요청 도착 순서에 의존하지 않습니다. 정확히 같은 통과 시각은 학생 ID로 안정적으로 정렬합니다. 완주 보너스는 없습니다.
- 미완주자는 종료 시 위치로 표시합니다. 정답·도전 수는 학습 기록이며 등수를 바꾸지 않습니다.

## 아이템

| 아이템 | 효과 |
|---|---|
| 지뢰 | 뒤에 설치, 0.5초 뒤 활성화, 밟은 친구를 튕겨 냅니다. 최대 14초 유지 |
| 미사일 | 바라보는 방향으로 발사, 직선 비행, 높은 점프로 회피 가능 |
| 바나나 | 뒤에 놓으며 밟으면 잠시 미끄러집니다. 최대 14초 유지 |
| 감속 영역 | 사용 위치 주변에 5초 동안 영역 생성, 다른 로봇 속도 38% |
| 보호막 | 4초 동안 아이템 공격·감속을 방어 |
| 질주 | 3초 동안 이동 속도 1.6배 |

자기 공격에 자신이 맞지 않습니다. 지뢰·바나나·미사일은 한 명에게만 소비됩니다. 아이템 사용 간격은 0.9초입니다. 교사가 방해 아이템을 끄면 보호막·질주만 지급합니다. 문제 풀이 중·완주 후에는 아이템을 사용할 수 없습니다.

## 화면과 교사 운영

학생 화면은 큰 경기장과 작은 순위·시간·아이템 표시로 구성합니다. 문제는 별도 팝업이며 그림 확대를 지원합니다. 휴대전화에는 조이스틱·점프·다이빙 버튼이 나타납니다. 전체 화면 버튼도 제공합니다. 교사는 순위 목록에서 관전할 친구를 고르고 일시 정지·재개·종료할 수 있습니다. 일시 정지는 경기 시간과 물리를 함께 멈춥니다.

학생은 별도 계정 없이 참여 코드와 닉네임을 사용합니다. 교사 접근 키는 학생에게 공유하지 않습니다. 결과는 14일간 재조회하며 CSV에 도착 등수·완주 여부·진행률·정답·도전·낙하 횟수를 담습니다. 학생은 종료 후 오답 해설 최대 6개를 확인합니다.

## 문제 가져오기와 교육 범위

엑셀 첫 시트 또는 CSV의 4지선다 문제를 1~500개, 파일당 3MB까지 가져옵니다. 엑셀 삽입 그림은 왼쪽 위를 해당 문제 행에 맞춥니다. 문제당 그림 1개, 1MB 이하이며 그림 URL도 사용할 수 있습니다. 단원 선택, 미리보기, 양식 다운로드를 유지합니다. 다른 반의 문제·그림·정답·접근 키는 공유하지 않습니다.

기본 24문제: 원소·원자·분자, 원자핵과 전자, 양성자·중성자·전자, 전하와 중성, 원자 번호, 이온, 원소 기호와 분자식. 선택 확장 4문제: 주기율표의 족·주기와 원자 번호 배열. 전자껍질은 포함하지 않습니다. 게임은 특정 학습지에 종속되지 않습니다.

## 구현 및 검증

새 방에 `arena` 설정을 저장합니다. 기존 에너지 레이스 방과 이전 퀴즈 방은 기존 규칙을 유지하므로 변경된 경기를 사용하려면 새 방을 만듭니다. 데이터베이스 스키마 변경은 없습니다. 학생별 버전·방 메타 버전·아이템 버전 조건으로 동시에 수정해 상태 유실과 중복 지급을 방지합니다.

물리 원본은 `lib/quiz-rally-arena.ts`입니다. 수정 후 `node scripts/build-quiz-arena.cjs`로 `public/labs/quiz-rally/arena-model.js`를 생성합니다. UI는 `arena.js`, `arena.css`에 있고 기존 앱의 입장·문제 가져오기·로봇 꾸미기를 연결합니다.

검증 명령: `node --test tests/quiz-rally-arena.test.cjs tests/quiz-rally-course.test.cjs tests/quiz-rally.test.cjs tests/quiz-rally-import.test.cjs tests/quiz-rally-journey.test.cjs`.

물리·점프·낙하·아이템·팝업 보호·정답 보상·중복 처리·서버 조작 검증·방별 격리·30명 동시 조작과 완주 순위·일시 정지·기존 방 호환성을 검사합니다. 실제 30~40대 교실 무선망 부하는 별도 검증 대상입니다. 웹소켓 게임 서버가 아닌 서버 상태 갱신과 클라이언트 예측 방식이므로 네트워크 지연에 따라 상대 위치 보정이 보일 수 있습니다.
