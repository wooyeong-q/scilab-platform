# 마지막 방송 · 교과 공용 방탈출 v3

플랫폼 저장소의 최신 main `3e5aa5b669d2372b40697089c1f6faa85943bec6`에서 시작한 배포 전 작업본이다. 기존 별과 우주의 조작형 퍼즐과 모둠 단서 공유 방식을 학교 괴담에 적용한다. 기존 프로그램과 홈페이지 목록은 변경하지 않는다.

진행 순서는 위의 표와 엑셀 행 순서다. 기존 자료의 참조를 유지하기 위해 원래 P1~P7의 ID를 바꾸지 않고 P8~P10을 중간에 배치했다. 약 40분을 목표로 작성하되 실제 소요 시간과 난도는 교과 자료와 학생의 협동에 따라 달라진다.

목표가 바뀌면 팝업과 상단 안내를 표시한다. 첫 목표는 “교실에 남겨진 기록을 찾으세요.”이다. 장소와 이동 목적을 안내하고 정답이나 조사할 물건 목록을 나열하지 않는다. 지도 네 장소는 처음부터 이동할 수 있으며 해결은 선행 기록으로 제한한다.

새 게임은 중앙 현관에서 시작한다. 잠긴 문을 다시 당기면 현관 스피커에서 교실로 이동하고 문을 닫아 두라는 방송이 나온다. 방송을 확인하면 첫 탐색 목표가 나타나고 학생이 지도를 열어 교실로 이동한다. 도입 중 끊었다가 이어도 확인하지 않은 장면부터 계속한다. 기존 저장의 탐색 위치와 수집 기록은 유지한다.

도서관의 대본에는 실제 방송을 방송실 녹음에서 확인하라는 안내가 있다. 하교 지시 두 줄은 공통 줄거리이며 P4에서 직접 대조한다. 별도로 마지막 수업의 복습 방송 네 줄을 엑셀로 교체한다. 차이는 미리 강조하지 않는다.

핏자국, 흐려지며 나타났다 사라지는 형체 네 번, 자연스러운 관찰 대사, 17:40에서 17:41로 넘어가는 엔딩을 유지한다. 상자 추락·모니터 켜짐·현관 소등 사건을 추가하고 사건 뒤에 조사할 대상이 남는다. 소리 없이도 모든 정보를 읽을 수 있고 공포 연출을 줄일 수 있다.

## 교사 사용

1. `/labs/common-escape/index.html`에서 교사 수업 준비를 연다.
2. 양식과 프롬프트를 내려받아 수업 자료와 함께 AI에 전달한다.
3. 받은 `.xlsx`를 업로드한다. 오류는 해당 시트·퍼즐·항목과 함께 알려 준다.
4. 전체 체험 또는 단계별 미리보기에서 조작·단서·정답을 확인한다.
5. 수업을 개설해 8자리 수업 코드를 안내한다. 학생은 모둠 번호와 1~4번 자리를 선택한다.
6. 교사가 일괄 시작하고 모둠별 목표를 확인한다. 학생 내보내기와 수업 종료를 지원한다.

현재 생성된 수업의 내용은 고정한다. 다른 엑셀은 새 수업에 적용한다. 같은 브라우저의 교사 접속 정보로 수업을 이어볼 수 있으며 접속 기간은 7일이다. 계정 기반 수업 목록과 홈페이지 프로그램 등록은 이번 범위에 포함하지 않는다.

## 협동과 저장

서버는 본인 자리와 비어 있는 자리의 자료만 반환한다. 잠시 접속이 끊겨도 자리는 유지한다. 학생이 나가거나 교사가 내보내야 빈자리로 바뀐다. 새 학생이 빈자리에 들어오면 다음 갱신부터 해당 자리의 자료가 분리된다.

탐색 위치, 자료 배치, 번호 입력, 표 회전과 음향 설정은 기기별로 유지한다. 수집·해결·힌트·탈출은 모둠 공유다. 정답은 서버에서 검증하며 완료 상태를 버전 조건으로 저장한다. 동시에 수집하거나 같은 답을 내도 진행을 덮어쓰지 않는다. 변경이 없으면 내용 없는 204 응답을 보내며, 실패 시 재요청 간격을 늘린다.

## 엑셀 규격

여섯 시트: 설정, 퍼즐, 자료, 대상, 모둠단서, 장치. `content.mjs`가 양식·검증·판정의 공통 기준이다. 이미지 없는 텍스트 자료와 HTTPS 그림, 자료 행 위에 배치한 PNG/JPG/WEBP를 지원한다. 원본 교과 문제의 의미까지 기계가 판정하지는 않으므로 교사 미리보기와 AI의 풀이 검토가 필요하다.

현재 양식은 `LAST-BROADCAST-3`이며 퍼즐 10개, 자료 40개, 대상 14개, 역할별 단서 32개다. 기존 `LAST-BROADCAST-2`의 7개 퍼즐은 교과 자료를 유지한 채 공통 학교 기록을 사용하는 세 퍼즐을 추가하여 가져온다. 새 양식에서는 추가 퍼즐도 교과별로 교체한다. P8은 각 역할의 두 자료 중 한 개씩 골라 총 네 개를 순서대로 배치한다. P9는 두 행·두 열의 조건을 모두 만족하는 유일한 칸에 배치한다. P10은 네 표시등의 목표 상태를 교과 자료로 결정하며 스위치 연결 관계는 공통 장치로 고정한다.

옛 12개 단답형 양식과 호환되지 않는다. 형식이 다른 파일을 억지로 변환하지 않고 새 양식을 안내한다. 수식·매크로·외부 통합문서 참조·지원되지 않는 셀 안 그림은 구체적인 오류로 거절한다.

## 로컬 검증

운영 DB와 사이트에는 접근해 변경하지 않았다. 스키마는 격리된 PGlite에서 실행한다. 정답·모둠 권한·동시 처리·다른 수업 격리와 실제 엑셀 재가져오기를 검사한다. DOM 어댑터 검사는 실제 조작 이벤트 흐름을 확인하며 브라우저의 배치·음향 검증을 대체하지 않는다.


## 최초 7단계 작업본의 확인 결과

- `node --test tests/common-escape-v2.test.cjs tests/common-escape-client.test.cjs tests/database.test.cjs`: 12개 통과. 격리된 DB에서 1·2·3·4인 모둠의 일곱 단계 완료, 단서 분리, 자리 충돌, 재접속, 교사 종료, 다른 수업 격리를 확인했다.
- `node tests/common-escape-controller.mjs`: 실제 버튼 동작으로 일곱 퍼즐, 잘못된 암호, 사진 재탐색, 목표 변경, 엔딩을 확인했다.
- 다운로드 체험 HTML도 같은 조작 검사를 통과했고, 그 파일에 포함된 엑셀 가져오기로 실제 작성된 XLSX를 읽었다.
- `npx tsc --noEmit --incremental false` 통과. `next build`는 컴파일·타입 검사를 통과한 뒤 기존 `/run/[id]` 정적 경로 수집에서 `DATABASE_URL` 미설정으로 멈췄다. 운영 연결 정보를 사용하거나 운영 스키마를 변경하지 않았다.
- 사용할 수 있는 브라우저 검증 수단이 없어 화면 배치·터치·음향은 실제 브라우저에서 아직 확인하지 않았다. 실제 학급 규모의 부하 검사도 하지 않았다.

`마지막방송_체험.html`은 배포 전 검토를 위한 독립 파일이다. 개인 체험, 교사 미리보기, 엑셀 검사를 지원한다. 모둠 수업 개설·입장은 플랫폼 서버 작업본에만 있다. 기본 체험은 수학 ‘정수의 계산’ 예시이며, AI로 완성한 다른 수업 엑셀을 올려 교체할 수 있다.

재생성: `node scripts/build-common-escape-preview.cjs /absolute/output.html`.

플랫폼 저장소 변경은 로컬 브랜치에만 있다. 원격 전송·운영 배포·홈페이지 등록을 하지 않았다.


## 탐색 과정 보완 · 2026-10-20

P1 정답은 잠금만 해제한다. 사물함 문을 열면 봉투와 두 기록의 내용을 확인할 수 있고, ‘반납 확인표와 기호표 챙기기’를 눌러야 소지품에 추가된다. 수집 전에는 도서관 단계가 열리지 않는다. 중간에 닫거나 이동해도 열린 사물함에서 계속할 수 있다.

P2의 공통 도서 A~D는 대출대, 반납 도서 선반, 책장 사이, 안쪽 책장에서 하나씩 챙긴다. 발견 전에는 자료 내용이 서버 응답에도 없고, 네 권을 모아야 반납함 퍼즐을 시작한다. 모둠원 누구나 공통 책을 수집할 수 있으며, 수집한 내용은 모둠 전체가 함께 확인한다. 개인 단서의 자리별 분리는 유지한다.

상태 버전 5는 잠금 해제, 사물함 열기, 기록 수집, 도서 수집을 구별한다. 이전 버전에서 이미 얻은 기록과 완료한 단계는 유지하며 이전 진행을 초기화하지 않는다. 엑셀의 여섯 시트와 퍼즐 형식은 유지한다.

보완 후 `common-escape-v2.test.cjs`와 `common-escape-client.test.cjs` 7개 통과. 자료 수집 전 진행 차단, 실제 획득 시점, 다른 모둠원의 공통 자료 열람, 중단 후 이어하기, 이전 저장 호환을 검사했다. 개별 체험의 버튼 흐름도 사물함을 열고 잠시 내려놓은 뒤 돌아와 챙기기, 책 네 권 탐색, 엔딩까지 통과했다.
## 공간 이미지 적용 · 2026-10-20

내장 이미지 생성 도구로 13개 이미지를 제작했다. 교실·도서관·방송실·현관·복도·운동장 배경 6개, 열린 사물함과 사진 대조용 변경 장면 4개, 투명 책·형체·손 소품 3개다. 원본 해상도와 알파를 유지하여 WebP로 인코딩했으며 전체 게임 이미지 용량은 약 2.3MB다. 제작 프롬프트는 `IMAGE-PROMPTS.md`, 원본 파일 대응은 `IMAGE-SOURCES.json`에 있다.

`art.mjs`의 탐색 좌표를 새 배경 속 실제 물건에 맞췄다. 교실은 사물함을 직접 열었을 때 열린 사진으로 바뀌고, 전원을 복구한 뒤 의자가 움직인 장면으로 바뀐다. 도서관의 네 권은 별도 투명 소품으로 렌더링하여 수집 시 각각 사라진다. 사진 비교는 배경 이미지의 동일한 영역을 확대하며 의자 이동·책등 뒤집힘·게시물 모서리 접힘이 실제 장면과 일치한다. 교과 글자, 수집 도서 ID, 암호, 장치 상태 표시는 코드로 렌더링한다.

등장 장면은 문 유리의 형체, 책장 옆의 얼굴과 어깨, 모니터 속 상반신, 유리문에 겹치는 손으로 구분했다. 이후 아래의 여자 귀신 자산 4종으로 교체했다. 공포 줄이기·동작 줄이기 설정을 유지하며, 배경은 비율을 유지하고 좁은 화면에서는 가로로 밀어 탐색한다.

독립 HTML은 14개 WebP·CSS·JS를 모두 내장하며 약 4.1MB다. 최신 파일의 실제 컨트롤러로 일곱 단계, 사물함 수집 전 중단·이어하기, 네 책 수집, 사진 대조, 잘못된 암호, 엔딩 및 엑셀 가져오기를 검사했다. 이미지 내장 바이트도 원본 자산과 대조했다. 네 장소의 탐색 좌표와 사진 비교 이미지를 렌더링해 시각 확인했다. 이 검사는 브라우저 스크린샷이 아니며 실제 브라우저 레이아웃·터치·음향 검증은 아직 하지 못했다. 운영 배포와 홈페이지 등록은 하지 않았다.
