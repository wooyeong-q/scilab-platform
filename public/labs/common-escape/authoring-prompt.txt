과목·단원·학년을 첨부 자료에서 알 수 있으면 그대로 사용해. 이 세 가지가 불명확할 때만 먼저 질문해. 자료에 없는 사실을 임의로 단정하지 말고, 수업 범위 안에서 정답과 근거가 명확한 내용을 선정해.

[만들 결과]
이미 구현된 방탈출의 자료를 채우는 작업이다. 새로운 게임이나 퍼즐 형식을 설계하지 말 것.
교과 지식을 적용해서 기록을 배치하고, 책을 대응시키고, 자료를 선별·분류하고, 두 기준을 조합하고, 방송을 대조하고, 선과 스위치를 조작하게 만들어 줘. 별도 객관식 퀴즈를 풀면 장치가 저절로 열리는 방식으로 바꾸지 마.
완성한 엑셀을 업로드하면 실제 자료 카드, 네 자리의 단서, 정답 판정, 힌트와 대사에 사용된다. 이 파일에 없는 기능이나 화면을 가정하지 마.

[먼저 설계할 것]
엑셀을 채우기 전에 P1·P2·P8·P3·P9·P4·P5·P10의 학습 목표, 학생이 수행할 판단, 자리별 정보, 정답 근거를 먼저 설계한다. 같은 정답을 숫자만 바꾸어 여러 형식에 반복 배치하지 않는다.
수업 범위가 허용하면 서로 다른 세부 학습 목표를 3개 이상 다룬다. 좁은 범위라면 개념을 억지로 늘리지 말고 해석·계산·적용·오류 판단 등 사고 과정을 바꾼다. 같은 판단 방법의 단순 반복은 2개 퍼즐 이내로 한다.
P1은 적응용으로 쉽게 만들되, 이미 적힌 숫자를 크기순으로 옮기기만 하는 문제보다는 자료에서 비교할 값을 한 번 해석하게 한다. 이후에는 각자 판단한 결과를 합쳐 장치를 조작해야 한다. 긴 설명이나 범위 밖 지식으로 난도를 올리지 않는다.
공통자료에 필요한 정의·기본 법칙은 줄 수 있다. 하지만 해당 카드에 적용한 계산 결과, 선택할 카드 목록, 완성된 과정 순서를 미리 써 주지 않는다. 예를 들어 분자식 해석 문제에서 식 옆에 원자별 개수를 모두 풀어 쓰거나, 순서 문제에서 실제 네 단계의 순서를 그대로 나열하지 않는다. 이 예시는 검토 기준이며 과학 문제를 강제로 넣으라는 뜻이 아니다.

[고정 이야기와 진행]
마지막 수업이 지정한 과목이었다. 수업이 끝난 뒤 가방을 챙겨 중앙 현관으로 내려왔지만 문이 잠겨 있다. 문을 다시 당기자 스피커에서 “교내에 남아 있는 학생은 교실로 이동해 주십시오.”, “교실 문은 닫아 두시기 바랍니다.”라는 방송이 나온다. 방송 확인 후 첫 목표를 받고, 학생이 지도를 눌러 교실로 이동한다. 교실, 도서관, 방송실, 중앙 현관은 지도에서 자유롭게 이동할 수 있다. 먼저 가 본 장소라도 앞선 자료가 없으면 장치를 해결할 수 없다.
교탁 아래 마른 핏자국이 남아 있고, 교복 차림의 형체가 잠깐씩 보인다. 잔혹한 묘사나 과장된 경고·예언 대사는 넣지 않는다.
진행은 아래 열 단계로 고정이다. P8~P10은 기존 양식과의 연결을 위해 유지하는 ID다. 숫자순이 아니라 아래 순서대로 진행한다.
P1 교실 / 기록 순서 복원 → 사물함 잠금 해제 → 학생이 사물함을 열고 봉투의 반납 확인표와 기호표를 직접 챙김
P2 도서관 / 네 곳에서 반납 도서와 기록을 직접 수집 → 반납함에서 도서 대응 → 천장 점검구에서 보관 상자가 떨어짐
P8 도서관 / 바닥의 상자를 직접 열어 기록 8장 확인 → 올바른 4장을 선별하고 순서 복원 → 반납 도서 보관함 열쇠 발견
P3 도서관 / 도서 자료 분류 → 방송 대본과 배치표 발견
P9 방송실 / 스스로 켜진 모니터의 기록을 두 기준으로 배치 → 녹음 장치 복구
P4 방송실 / 원본 대본과 녹음 대조 → 제어함 열림
P5 방송실 / 전선과 단자 연결 → 현관 전원 복구, 사진 세 장 발견
P6 교실·도서관·현관 재탐색 / 사진과 달라진 물건 조사 → 사진 순서대로 번호를 읽어 방송실 보조 서랍 열기, 이동 기록과 점검 기록 발견
P10 중앙 현관 / 조명이 꺼진 뒤 비상 회로 점검 → 목표 표시등을 판단하고 연동 스위치 조작 → 번호 장치 안정화
P7 중앙 현관 / 기호표·배치표·이동 기록·점검 기록 통합 → 마지막 잠금 해제
상자 낙하·모니터 켜짐·현관 소등 및 짧게 나타났다 사라지는 형체는 게임의 고정 사건이다. AI가 추가 영상·효과음·공포 사건을 만들거나 내용에 새로운 조작을 약속하지 않는다. 목표 팝업과 장소 이동 안내는 게임이 제공한다. 현관의 방송을 확인한 뒤 나오는 첫 탐색 목표는 “교실에 남겨진 기록을 찾으세요.”이다. 대사에 조사 위치나 정답을 나열하지 마. 교과별로 새로운 방, 등장인물, 분기, 아이템, 제한 시간 또는 추가 입력 장치를 만들지 마.

[네 명이 함께 푸는 조건]
한 모둠은 1~4번 자리로 구성된다. 각 자리에는 서로 다른 자료가 배정된다. 자신의 자료를 설명하고 다른 사람의 기록과 연결해야 해결할 수 있게 구성해.
인원이 적으면 게임이 빈자리의 자료를 남은 학생들에게 보여 준다. AI가 2인용·3인용 문제를 따로 만들지 않는다.
모든 자료를 읽는 한 사람이 정답까지 바로 말할 수 있는 공통 지문에 단서를 몰아넣지 마. 각 자리의 단서에 풀이상 의미가 있어야 한다. 단순히 “친구와 상의하세요”라는 문장만 네 번 쓰지 마.
다른 자리의 자료 원문이나 정답 배치를 한 학생의 단서에 복제하지 마. 각자가 설명하는 한 가지 이상의 핵심 정보가 있어야 한다.
공개 범위를 구분해 설계한다. 공동과제·공통자료·자료의 표시이름·대상 이름은 모두에게 보인다. 담당 1~4의 자료 내용과 모둠단서는 해당 자리에게 보이며, P2의 발견한 책과 P4의 녹음은 공통 공개다. P4의 원본 대본만 한 줄씩 나뉘어 보인다.
모둠단서는 일반적인 공부 조언이 아니라 해당 기록의 해석에 쓰이는 조건·기준·대조 근거로 만든다. 이미 공동과제나 공통자료에 쓴 문장을 네 자리에서 다시 설명하는 것으로 채우지 않는다. 다만 필요한 수업의 기본 개념까지 숨겨서 모호하게 만들지는 않는다.
공개된 정보만으로 모든 대응을 확정할 수 있으면 역할 분담을 다시 설계한다. 특히 P2는 책이 모두 공개되므로 네 자리의 반납 기준이 실제 대응 판단에 필요해야 한다. 일대일 대응에서 마지막 한 칸을 소거법으로 알아내는 것은 허용하되, 처음부터 단서 없이 전부 풀리는 구성은 피한다.

[엑셀 공통 규칙]
시트는 설정, 퍼즐, 자료, 대상, 모둠단서, 장치다. 시트 이름과 5행의 열 이름을 그대로 유지한다. 데이터는 6행부터 들어간다.
양식버전 LAST-BROADCAST-3를 유지한다. 퍼즐ID, 장소, 형식, 자료ID, 대상ID와 배정된 자리 번호는 기본 양식 그대로 둔다. 기존 데이터 행을 삭제하거나 중복하지 않는다.
회색 칸은 유지하고, 연노랑 칸에 내용을 작성한다. 필요하면 제목과 대사를 자연스럽게 수정하되 이야기 진행과 보상은 유지한다.
수식, 매크로, 외부 통합문서 참조, 별도의 JSON 문자열을 넣지 않는다. 계산 결과도 값으로 입력한다. 정답 열의 내용을 학생용 자료·대사에 그대로 반복하지 않는다.
기본 양식은 P1~P5·P8~P10의 자료 40개, 대상 14개, 모둠단서 32개를 사용한다. P6·P7 자료와 역할 분담은 장치 시트에서 자동으로 생성하므로 자료·대상·모둠단서 시트에 P6·P7 행을 추가하지 않는다.

[한 화면에 보이도록 쓰는 분량]
아래 글자 수는 공백·문장부호를 포함한 작성 기준이다. 프로그램의 최대 입력 허용량까지 채우지 않는다. 문제·카드·단서가 한 화면에 함께 보이도록 중복 설명을 덜어 낸다.
제목 24자, 공동과제 80자, 공통자료 80자, 도입대사·완료대사 각각 60자, 힌트 각각 80자 이내.
자료 표시이름 12자, 자료 내용 50자 이내. P10은 두 판단을 포함하므로 70자 이내. P4 기준자료는 50자 이내. 단서 제목 20자, 단서 내용 70자 이내.
대상 이름은 16자 이내. P9는 행·열 이름 각각 8자 이내로 쓰고 |로 연결한다. 행·열 이름은 공동과제와 일치시킨다.
표·여러 줄 목록·긴 서론을 한 셀에 몰아넣지 않는다. 한 문장에 하나의 판단을 담고, 꼭 필요한 수치·단위·조건·부정 표현은 생략하지 않는다. 필수 조건을 빼야만 짧아진다면 더 짧은 사례로 바꾼다. 글자 축소·스크롤·다음 페이지·별도 자료창을 전제로 쓰지 않는다.
이 분량만으로 모든 기기의 화면 적합성이 보장되지는 않는다. 화면을 직접 확인하지 못했으면 검토 결과에 '화면 미확인'이라고 적고 확인했다고 말하지 않는다.

[1. 설정 시트]
항목 / 값 / 설명
수업명, 과목, 단원, 대상을 채운다. 제목은 “마지막 방송 · [단원]”처럼 짧게 쓴다. 양식버전은 변경하지 않는다.

[2. 퍼즐 시트]
퍼즐ID / 장소 / 형식 / 제목 / 공동과제 / 공통자료 / 도입대사 / 완료대사 / 힌트1 / 힌트2 / 힌트3
공동과제: 실제 조작 목표와 교과적 판단 기준을 명확히 제시. 80자 이하. 예: 크기순 배치라면 오름차순인지 내림차순인지 명시.
공통자료: 모두가 알아야 할 상황·용어·기본 조건. 80자 이하. 다른 자리의 비밀 자료와 적용 결과를 이 칸에 모으지 않는다. 불필요하면 비워도 된다.
제목: 24자 이하. 학생이 조사한 물건과 관련된 자연스러운 이름.
도입대사·완료대사: 각각 60자 이하, 보통 1문장. 학생이 관찰한 사실 중심. “운명이 너를 부른다”, “돌아오지 못한다” 같은 과장된 대사 금지.
힌트 1: 확인할 자료와 생각의 방향. 힌트 2: 사용할 개념과 조합 기준. 힌트 3: 구체적인 풀이 절차. 각 80자 이하. 완성된 배치·정답 번호·암호를 직접 쓰지 않는다.
P1 완료대사는 사물함 잠금이 풀린 상황까지만 쓴다. 반납 확인표·기호표를 챙기는 과정은 게임에서 별도로 진행하므로 문제를 풀자마자 획득했다고 쓰지 않는다.
P2 완료대사는 반납 확인까지만 쓴다. 상자는 그 뒤에 떨어지며, P8을 풀어야 보관함 열쇠를 얻는다. P9 완료대사는 녹음 장치가 복구되는 상황, P10 완료대사는 현관 번호 입력창의 전원이 안정되는 상황이다.
P6·P7은 기본 과제와 힌트를 유지해도 된다. 이 두 단계는 공통 탐색·종합 퍼즐이며 교과 퀴즈를 추가하는 자리가 아니다.

[3. 자료 시트]
퍼즐ID / 자료ID / 표시이름 / 내용 / 담당 / 정답 / 기준자료 / 그림주소 / 그림설명
표시이름: 카드·책·선의 짧은 이름. 12자 이하. 정답 순서를 연상시키는 이름은 피한다.
내용: 학생이 해석할 식, 문장, 사례, 관찰 기록 등. 50자 이하(P10은 70자). 해석할 원자료를 주고 학생이 계산할 중간값이나 개념 이름을 정답처럼 덧붙이지 않는다.
담당: 0은 모두 공개, 1~4는 해당 자리에게만 내용과 그림 공개. 다른 학생에게는 표시이름만 보인다. 양식의 배정을 유지한다.
정답: 아래 형식별 규칙을 엄수한다. 정답 설명은 이 칸에 쓰지 않는다.
기준자료: P4에서만 50자 이하의 원본 대본을 입력한다. 다른 형식에서는 빈칸.
그림주소: 그림 없이 풀 수 있으면 빈칸. 실제로 확인된 HTTPS 주소만 허용하고 추측한 주소를 쓰지 않는다. 그림을 첨부할 수 있으면 자료 시트의 해당 데이터 행 위에 PNG/JPG/WEBP 한 개를 배치한다. 그림 왼쪽 위가 그 자료의 행 안에 있어야 한다. 그림당 500KB 이하, 전체 파일 3MB 이하.
그림설명: 그림을 넣었으면 반드시 입력. 200자 이하. 정답을 밝히지 않는 대체 설명. 제공하지 않은 그림·그래프를 보라고 지시하지 않는다.

[퍼즐 형식별 작성 방법]
P1 order: 자료 4개. 담당은 1,2,3,4 한 장씩. 정답은 각 카드가 들어갈 위치 1~4이며 중복 없이 사용한다. 학생은 네 카드를 1번째~4번째 홈에 꽂는다. 교과 개념에 근거한 순서를 만들고, 동점이나 여러 가지 가능한 순서가 생기지 않게 한다. 값 비교, 과정 복원, 문맥 순서 등 단원에 적합한 하나의 기준을 선택한다. 대상 시트에 P1 행은 없다.

P2 match: 공통 도서 자료 4개와 반납 칸 T1~T4. 자료ID A~D와 담당 0을 유지한다. 네 책은 대출대·반납 도서 선반·책장 사이·안쪽 책장에서 직접 챙겨야 한다. 공통 자료는 발견 후 모둠 전체에게 공개된다는 뜻이며, 미발견 자료가 자동 제공되는 것이 아니다. 각 도서의 정답은 대상ID 하나다. 모든 칸에 책 한 권씩 들어가야 하므로 T1~T4를 한 번씩 사용한다. 대상의 표시이름과 네 사람의 반납 기준을 종합해야 대응을 결정할 수 있게 만든다. 각 모둠단서는 대응 관계에 필요한 독립적인 정보를 제공한다.
반납 칸은 중립적인 표식이나 위치 이름으로 구분하고, 그 칸의 반납 조건을 자리별 모둠단서에 나누어 둔다. 단서의 조건과 책의 사례를 교과적으로 해석해야 대응이 정해져야 한다. 책 본문에 개념 이름을 쓰고 같은 이름의 반납 칸에 넣게 하는 단어 맞추기를 만들지 않는다. 네 단서를 가리고 공통자료·책·대상 이름만으로 전체 대응을 알아낼 수 있는지 반드시 점검한다.

P3 classify: 자료 8개. 1~4번 자리에게 두 장씩 배정한다. 양식의 두 분류함 T1·T2를 사용한다. 각 자료 정답은 T1 또는 T2. 두 분류함 모두 실제로 사용하고, 중복 소속·애매한 경계가 생기지 않도록 기준을 명확히 제시한다. 정의의 복창에 그치지 않고 새로운 사례를 개념에 따라 분류하도록 한다.

P4 compare: 자료 4개가 마지막 수업의 복습 방송이다. 담당은 모두 0. 내용에는 녹음된 문장, 기준자료에는 올바른 원본 대본을 쓴다. 원본은 순서대로 1~4번 자리에게 하나씩 보이고, 녹음은 모두에게 보인다.
정답은 일치 또는 수정만 입력한다. 일치인 경우 내용과 기준자료를 글자와 문장부호까지 똑같이 쓴다. 수정인 경우 학습 개념에 영향을 주는 내용을 일부 바꿔 명확한 오류를 만든다. 단순한 동의어·띄어쓰기·문체 차이를 오류로 만들지 않는다. 일치하는 줄과 수정할 줄이 각각 하나 이상 있어야 한다.
실제 화면에서는 달라진 녹음 줄을 누르면 '수정 표시'가 남는다. 일치하는 줄은 누르지 않는다. 일치/수정 두 버튼을 고르는 화면이 아니다. 공동과제는 '각자의 원본과 대조해 달라진 줄만 표시하세요'처럼 쓰고, 하교 안내와 복습 방송 모두 대조 대상임을 포함한다.
모둠단서에는 담당 원본을 해석하는 데 필요한 개념이나 주의점을 추가한다. 정답이 “수정”이라고 직접 말하지 않는다.
게임은 여기에 고정 하교 안내 두 줄을 추가한다. 원본은 “중앙 현관으로 이동 / 교실 문은 열어 두기”, 녹음은 “교실로 이동 / 교실 문은 닫아 두기”다. 녹음은 시작 장면에서 현관 스피커로 들은 안내와 같다. 이 두 줄은 엑셀에 중복해서 넣지 않는다.

P5 connect: 연결선 자료 4개와 단자 T1~T4. 담당은 1,2,3,4 하나씩. 각 선의 정답은 연결할 대상ID이며 T1~T4를 한 번씩 사용한다. 각자가 계산·추론한 결과를 공유해야 연결할 수 있게 한다. 단자의 표시이름에는 계산값·관련 개념·맞는 설명 등을 넣을 수 있다. P2와 학습 내용이나 사고 과정을 그대로 반복하지 않는다. 자료에 계산 과정이나 완성된 해석을 써 두어 교과적 판단을 건너뛸 수 있게 하지 않는다.

P8 select-order: 상자 속 자료 8개. 담당 1~4에게 두 장씩 배정하며 각 자리의 두 장 중 정확히 한 장만 올바른 기록이다. 학생은 필요한 기록 4장을 고른 뒤 네 홈에 순서대로 배치한다. 선택할 기록의 정답은 최종 위치 1~4를 한 번씩 사용하고, 버릴 네 기록의 정답은 모두 제외로 쓴다. 자료·단서만으로 무엇을 남기고 무엇을 제외할지, 선택한 네 장은 어느 순서인지 모두 판단할 수 있어야 한다. 자료ID나 담당 번호가 정답 순서가 되지 않게 섞는다. 단순히 맞는 문장을 고르는 데서 끝내지 말고 선택 뒤 시간·양·인과·과정 등 교과적으로 명확한 순서 판단이 필요하게 한다. 서로 다른 자리의 유효한 기록이 모두 있어야 완성되도록 한다.
선별과 순서 판단은 별도로 검증한다. 공통자료에는 판단 규칙만 쓰고, 선택한 네 기록의 내용에 해당하는 완성 순서를 화살표나 번호로 나열하지 않는다. '처음·직후·완성'이라는 이름만 보고 정렬되도록 하지 않는다. 시간순이라면 실제 선후 관계가 있어야 한다. 같은 상태를 계산한 문장과 그 상태에 이름을 붙인 문장을 별개의 사건인 것처럼 시간순으로 강제하지 않는다. 순서가 애매하면 명확히 비교할 수 있는 양이나 근거 있는 과정으로 다시 설계한다.

P9 matrix: 모니터 기록 4개. 담당 1~4에게 한 장씩 배정한다. 두 가지 독립적인 기준을 동시에 적용해 2×2 화면을 복원한다. 예: 상태와 조건, 시기와 지역, 표현의 기능과 시점 등. 각 칸에는 한 장씩, 정답 T1~T4를 한 번씩 사용한다. 대상 표시이름은 T1=행1|열1, T2=행1|열2, T3=행2|열1, T4=행2|열2 형식이다. 동일한 행·열 이름은 글자까지 일치시킨다. 세로줄 | 는 행과 열을 나누는 구분자이며 각 대상 이름에 한 번만 넣는다. 각 기준이 서로 겹치지 않고 빠지는 자료도 없도록 경계를 공동과제에 명시한다. 두 기준 중 하나만으로는 칸을 결정할 수 없어야 한다.

P10 circuit: 네 표시등 A~D에 판단할 기록을 붙인다. 담당 1~4에게 한 장씩, 자료ID A~D의 행 순서를 유지한다. 각 기록은 같은 교과 내용에 관한 두 조건을 함께 판단하도록 구성한다. 예를 들어 두 조건이 모두 맞는 기록만 켜야 한다는 공동 규칙을 쓸 수 있다. 정답에는 켜짐 또는 꺼짐만 입력하고 두 상태가 각각 하나 이상 있어야 한다. 두 조건 중 하나가 항상 맞는 식으로 첫 조건을 장식으로 만들지 않는다. 범위 안에서 두 조건 모두 판단에 기여하도록 참·참, 참·거짓, 거짓·참 등의 사례를 섞는다. 조건의 참·거짓을 서로 논의해 목표 상태를 정한 뒤 연동 스위치로 그 모양을 만들어야 한다.
장치의 연결은 고정이다. 스위치 I는 A·B, II는 B·C, III는 C·D, IV는 A·B·D의 상태를 한꺼번에 반전한다. 시작은 모두 꺼짐이다. 동일한 스위치를 두 번 누르면 원래대로 돌아간다. 연결 표시는 게임에 있으므로 모둠단서를 연결표 복사로 채우지 말고, 담당 교과 기록을 판단할 수 있는 개념·근거를 넣는다. 스위치 연결 자체를 전기 단원 문제로 바꾸지 않는다. 어떤 과목도 같은 장치에 교과 기록을 붙여 사용한다. 네 목표 상태와 이를 만드는 스위치 조합을 직접 검산하되 정답 조합을 학생용 대사나 힌트에 공개하지 않는다.

[4. 대상 시트]
퍼즐ID / 대상ID / 표시이름
P2는 책을 넣을 네 칸, P3는 두 분류함, P5는 네 단자, P9는 두 기준을 결합한 네 칸이다. P8과 P10은 대상 행이 없다. 자료 시트 정답에 적힌 T1~T4와 정확히 연결되어야 한다. 표시이름은 16자 이하로 쓴다(P9는 행·열 이름 각각 8자 이내). 정답 ID를 이름에 덧붙여 해결을 알려 주지 않는다.

[5. 모둠단서 시트]
퍼즐ID / 자리 / 제목 / 내용
P1~P5·P8~P10에 각각 자리 1~4의 단서가 반드시 하나씩 있어야 한다. 제목 20자 이하, 내용 70자 이하. 해당 자료의 판단에 필요한 관찰·조건·대조 자료로 구성한다. 제목은 자료에 맞게 짓고, 모든 단서를 단순히 “P번호 · 자리 참고”로 채우지 않는다.
학생은 자신의 자료만 보고 설명하며, 배치 중인 카드는 각자의 화면에서 움직인다. 장치를 맞게 해결하면 모둠 전체가 다음 단계로 진행한다. 특정 학생이 동시에 버튼을 눌러야 하는 조건이나 게임에 없는 협동 기능을 요구하지 않는다.

[6. 장치 시트]
항목 / 값 / 설명
기본값은 검증된 공통 퍼즐이다. 별도 요청이 없으면 이 시트를 그대로 유지한다.
사진_의자, 사진_책, 사진_게시물: 각 장소에서 발견하는 숫자 0~9. 각각 1~3번 자리에 공개.
사진_순서: chair, book, notice를 한 번씩 |로 구분. 4번 자리에게 공개. 이 순서대로 발견 숫자를 이어 세 자리 서랍 번호를 만든다. 앞자리 0도 유지한다.
기호_○, 기호_△, 기호_□, 기호_☆, 기호_◇, 기호_＋: 각각 다른 숫자 0~9. 1번 자리에게 공개.
배치표: 회전 전 3×3 칸의 기호 9개. 왼쪽 위부터 가로로 읽어 |로 구분. 2번 자리에게 공개.
시작칸, 제외칸: 회전 전의 칸 번호 1~9. 서로 다르게 한다.
이동경로: right/down/left/up을 |로 구분하여 6~12번. 3번 자리에게 공개. 원래 왼쪽에 붙은 현관 표시를 아래로 맞추므로, 표를 반시계 방향으로 90도 회전한 뒤 경로를 따라간다.
4번 자리의 규칙은 게임이 고정 제공한다. 시작칸은 적지 않고, 화살표마다 한 칸 이동하며, 도착한 칸만 기록한다. 제외칸은 통과하되 적지 않는다. 남은 기호를 기호표로 변환한다.
장치 값을 바꿀 때에는 경로가 표 밖으로 나가지 않고, 제외칸을 한 번 이상 지나며, 남는 번호가 5~10자리인지 직접 검산한다. 최종 번호를 다른 시트에 적거나 추가 암호 칸을 만들지 않는다.

[완성 전 반드시 직접 검토]
1. 정답 열을 가린 채 학생에게 제공되는 자료만으로 먼저 풀고, 그 결과를 정답 열과 비교한다. P1 순서, P2 대응, P8 선별·순서, P3 분류, P9 두 기준, P4 수정 표시, P5 연결, P10 목표 상태와 스위치 조합을 모두 검산한다. 이미 써 둔 정답을 설명하는 것으로 검증을 대신하지 않는다.
2. 교과 사실·계산·단위·기호·적용 조건을 확인한다. 틀린 진술을 의도한 P4·P8·P10은 올바른 근거가 함께 있고 정답 처리와 일치하는지 확인한다. 범주가 겹치거나 동점이 생겨 여러 답이 가능한 경우 사례나 기준을 수정한다. 출처를 확인할 수 없는 세부 사실은 단정하지 않는다.
3. 공개 정보만으로 전체 정답이 드러나는지, 각 자리의 자료·단서가 어떤 판단에 쓰이는지 점검한다. '친구와 상의'나 공통 정의의 반복만 있는 단서는 바꾼다. P2는 특히 네 단서를 가린 상태로도 해결되는지 확인한다.
4. P8의 남길 4장과 제외할 4장을 각각 설명하고, 선택한 4장의 가능한 24가지 순서 중 제시된 기준에 맞는 순서가 하나인지 확인한다. 공통자료가 완성 순서를 공개하거나 동시인 상태를 억지로 시간순으로 나누면 다시 만든다.
5. P10은 네 기록의 두 조건을 각각 참/거짓으로 검산하고 목표 켜짐·꺼짐을 구한다. 모두 꺼진 상태에서 스위치 4개를 각각 0회/1회 누르는 16가지 조합을 확인한다. 목표에 도달하는 조합이 있어야 한다. 단순 반복 조작으로 난도를 과장하지 않는다.
