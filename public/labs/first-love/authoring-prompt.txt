오늘, 너에게 — 교과 자료 작성 프롬프트 v3.1

첨부한 오늘너에게_공통교과양식_v3.xlsx와 교과 자료로 수업용 .xlsx 한 파일을 작성하세요.
수업명: [입력] / 과목: [입력] / 학년: [입력] / 단원·성취기준: [입력]
학생이 읽을 실제 원문·그림·자료: [첨부 또는 입력]
자료가 없으면 임의의 사실을 교과서 내용으로 꾸미지 말고 필요한 범위를 먼저 확인하세요.

[학생이 이해할 수 있는 문제부터 설계]
먼저 “이 자료에서 무엇을 알아내야 하는가?”를 한 문장으로 정하고, 그 답을 입력하기 좋은 장치를 고릅니다.
학생에게 보이는 흐름은 주변 사물에서 기록 발견 → 배운 개념으로 자료 해석 → 같은 번호의 입력칸에 사용 → 장치 전체 확인입니다.
문제의 핵심은 교과 자료의 해석입니다. 조작법이나 임의의 암호 규칙을 알아내는 데 대부분의 시간을 쓰게 하지 마세요.
짧은 목표 한 줄, 네 역할의 서로 다른 원자료, 모든 학생이 볼 수 있는 후보 자료를 제공합니다. 긴 이야기나 대사를 문제에 덧붙이지 않습니다.

[이야기와 역할]
축제 정리 중 도하가 윤재의 파란 편지 봉투를 체험 부스 수납함에 넣었습니다. 네 친구가 남은 장치를 풀어 편지를 되찾습니다.
자리 1=윤재, 2=도하, 3=시우, 4=민우. 선택은 개인 단서를 맡는 역할이며 고백 주인공은 항상 윤재입니다. 서아는 선택 대상이 아닙니다.
P1~P8의 퍼즐ID와 장소는 유지합니다. P1·P2 classroom, P3·P4 library, P5·P6 club, P7·P8 corridor.
P9 사진 대조·점검 열쇠와 P10 수납함은 공통 마지막 단계입니다. 퍼즐 행을 추가하지 않습니다.

[교과 문제 형식 — P1~P8 어느 자리에서나 선택]
dials: 네 자리 숫자 자물쇠. 단서의 답이 되는 개념·낱말·기호를 찾고, 공개 번호표에서 해당 번호를 찾아 입력합니다. 번호표는 자료 A=1, B=2… 순서로 자동 표시됩니다. 학습 내용 자체가 숫자일 필요는 없습니다.
circuit: 네 기록을 개념·설명·범주와 연결하는 판. 왼쪽 입력선과 같은 번호의 단서를 해석해 오른쪽 대상에 연결합니다. 여러 선이 같은 대상에 연결되어도 됩니다.
frames: 그림·문장·지도·표 조각을 골라 네 칸에 놓는 복원판. 각 단서와 맞는 자료를 선택합니다. 그림 없이 문장이나 표현으로도 만들 수 있습니다.
key: 네 기록에 맞는 개념·낱말 조각을 열쇠홈에 끼웁니다. 홈 1~4는 입력 위치이며 시간순이나 과정 순서가 아닙니다.
국어의 문맥·품사·관용 표현, 사회의 지도·사례, 과학의 관찰·모형, 수학의 조건·표, 영어의 상황·표현처럼 과목의 자연스러운 자료를 사용하세요.
홀짝·숫자 크기·연대순·임의의 방향 규칙을 일괄 적용하지 마세요. 회전이나 뒤집기는 실제 학습 목표에 방향이 포함된 경우에만 사용합니다.
같은 장치의 예: 과학 자물쇠는 분자식에서 원소 찾기 → 번호표, 국어 자물쇠는 문맥에서 품사 판단 → 번호표. 개념을 적용해야 풀리게 하며 정답 단어를 그대로 복사하는 자료는 피합니다.

[선택해서 유지할 수 있는 탐색 장면]
기본 예시에는 P1 riddle(사물 수수께끼), P2 jigsaw(배치도 조각), P5 tools(거울·집게), P6 film(필름 겹치기)이 포함됩니다.
짧은 이야기 탐색으로 유지하려면 해당 퍼즐·자료·대상·모둠단서 행을 양식 그대로 둡니다. 이 장면을 교과 문제로 바꾸려면 형식을 dials/circuit/frames/key로 변경하고 그 퍼즐의 자료·대상·네 단서도 새로 작성하세요.
형식은 그대로 두고 고정 장면의 내용만 변경하면 업로드 오류가 표시됩니다. 변경 사항을 조용히 무시하지 않습니다.
교과 문제만 원하면 P1~P8을 모두 네 학습 형식으로 교체할 수 있습니다. 기본 예시의 과학·국어는 여러 개념을 섞은 사용 예시이므로 실제 수업은 지정 단원과 성취기준으로 좁혀 작성합니다.

[단서가 실제로 필요한지]
각 역할은 해석할 실제 문장·관찰·사례를 하나씩 갖습니다. 한 문장을 네 조각으로 자르거나 정답 번호만 나누지 마세요.
개인 단서는 주변 사물을 발견한 역할에만 보입니다. 공개 자료에 개인 관찰값을 중복하지 않습니다.
역할 1의 단서는 입력칸 T1, 역할 2는 T2, 역할 3은 T3, 역할 4는 T4에 사용합니다. 화면이 이 연결을 표시하므로 내용도 일치해야 합니다.
정답 열을 가리고 네 단서로 전체 답을 풉니다. 이어 각 역할의 단서를 하나씩 빼서 가능한 전체 답이 최소 두 개 남는지 확인합니다.
자물쇠·연결판은 같은 자료를 여러 번 사용할 수 있습니다. 그림판·열쇠는 사용하지 않는 후보를 최소 한 개 포함해 마지막 조각이 소거만으로 정해지지 않게 합니다. 네 번째 단서를 억지 앞뒤 조건으로 만들지 마세요.
해설에 교과 판단 근거, 전체 답, 각 단서가 없을 때 구분할 수 없는 후보를 구체적으로 기록하세요. 프로그램의 구조 검사와 교과 내용 검토를 구분합니다.

[파일 구조]
기존 여섯 시트 이름과 열 이름, 퍼즐ID·장소·자료ID·담당·장치 값은 유지합니다. 수식·매크로·외부 연결 없이 값으로 작성합니다.
설정: 항목 / 값 / 설명
퍼즐: 퍼즐ID / 장소 / 형식 / 제목 / 공동과제 / 공통자료 / 해설 / 힌트1 / 힌트2 / 힌트3
자료: 퍼즐ID / 자료ID / 표시이름 / 내용 / 담당 / 정답 / 중간정답 / 기준자료 / 조건통과 / 그림주소 / 그림설명
대상: 퍼즐ID / 대상ID / 종류 / 표시이름
모둠단서: 퍼즐ID / 자리 / 제목 / 내용 (기존 검증조건 열은 비움)
장치: 항목 / 값 / 설명
설정 양식버전은 TODAY-TO-YOU-3. 미소_최대오답=5, 당황_최대오답=14를 기본으로 유지합니다.
제목 40자, 공동과제 65자, 공통자료 120자, 해설 2000자, 힌트 3개 각각 90자 이내.
자료 표시이름 18자, 내용 50자, 그림설명 100자 이내. 단서 제목 24자, 내용 150자 이내. 가능하면 단서 1~2문장, 90자 이하.
모둠단서는 P1~P8마다 자리 1~4 한 행씩 총 32행입니다.
대상은 교과 문제마다 T1~T4 네 행, 종류=입력, 표시이름은 16자 이내. 예: 암호 1, 연결선 1, 복원칸 1, 열쇠홈 1. 단서에 적힌 위치와 일치시킵니다. 이전 파일처럼 대상이 비어 있으면 기본 이름을 표시합니다.

[정답 입력 규칙]
모든 자료의 담당은 0. 자료ID는 각 퍼즐에서 A부터 차례대로 작성합니다. 기준자료·조건통과는 비웁니다. 정답 열은 학생에게 전송하지 않습니다.
dials/circuit: 자료 2~8개. 정답 열에는 그 자료를 쓸 입력칸 번호를 적습니다. B를 첫 칸에 쓰면 B의 정답=1. B를 첫째와 셋째 칸에 쓰면 1|3. 쓰지 않는 자료는 빈칸. 전체 자료에서 1,2,3,4를 각각 한 번 배정합니다. 중간정답은 비웁니다.
자물쇠 예: A=명사, B=동사, C=형용사, D=부사이며 정답이 A:2, B:1|3, C:빈칸, D:4이면 입력 암호는 2124입니다. 정답 열에 최종 암호를 그대로 적지 마세요.
frames/key: 자료 5~8개. 정답 열에 위치 1~4를 각각 한 번 배정하고 나머지는 제외. 중간정답은 기본적으로 모두 빈칸입니다. 이때 화면에 회전 버튼이 나오지 않습니다.
실제 학습 목표에 180도 방향 판단이 있을 때만 모든 자료의 중간정답에 0(원래 방향) 또는 1(180도 회전)을 넣습니다. 일부만 비우지 않습니다. 이 방식의 기존 4조각 파일도 지원하지만 새 문제에는 미사용 후보를 포함하는 방식을 우선합니다.

[그림과 원자료]
그림판에는 실제 학습 그림·지도·도표·원문 조각을 사용하세요. 필요한 그림이 없으면 제공을 요청하거나, 정확한 텍스트 자료를 쓰는 형식을 선택합니다.
자료 시트의 데이터 행 위에 그림 한 장씩 놓고 왼쪽 위 모서리가 해당 행 안에 오게 합니다. PNG·JPG·WEBP 한 장 500KB 이하, 전체 파일 3MB 이하. 그림주소는 비우고 그림설명에 대체 설명을 적습니다. 셀 안 그림·웹주소·SVG·GIF는 지원하지 않습니다.
학생은 ‘자료 확대’로 그림과 세부 내용을 볼 수 있습니다. 작은 그림에서만 구별되는 차이를 정답의 유일한 근거로 쓰지 마세요.

[학생 행동과 힌트]
문제·단서·후보·입력 버튼은 스크롤 없이 보입니다. 긴 단서는 페이지로 넘깁니다.
전체 답안을 명시적으로 제출했을 때만 판정합니다. 선택·이동 자체는 오답이 아닙니다. 기본 riddle/tools/film 탐색과 P9 관찰은 오답에 넣지 않습니다. 해당 자리를 학습형으로 바꾸면 다른 학습 문제와 같은 방식으로 채점합니다.
맞은 칸 표시, 맞힌 개수, 부분 정답 잠금, 정답 조각만 붙는 기능은 요구하지 않습니다.
힌트는 관찰 대상 → 배운 개념 적용 → 조작 방법 순서. 다른 역할의 비밀 자료나 완성 답을 공개하지 않습니다.

[완료 전 확인]
1. 참고 자료와 학년·성취기준·용어·사실·단위·그림을 대조합니다.
2. 각 문제의 목표를 읽으면 무엇을 찾고 어디에 넣을지 알 수 있는지 확인합니다.
3. 정답 열을 가리고 풀어 보고 정답·해설과 비교합니다.
4. 단서를 하나씩 빼서 답이 최소 두 개 남는지 구체적인 후보로 검산합니다.
5. 여섯 시트, P1~P8, 형식별 후보 수·정답·입력칸 이름을 확인합니다.
6. 저장한 .xlsx를 다시 읽어 확인합니다. 실제 업로드나 미리보기를 하지 않았다면 했다고 쓰지 마세요.
