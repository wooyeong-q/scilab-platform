〈오늘, 너에게〉 공통 교과 협동 방탈출 작성 요청 · TODAY-TO-YOU-2

첨부한 v2 엑셀 양식과 수업 자료로, 학생 네 명이 서로 다른 단서를 나누어 풀 수 있는 .xlsx 한 개를 만들어 주세요. 과목·학년·단원·학습 목표는 교사가 지정한 범위를 따릅니다. v1 파일의 버전만 바꾸지 말고 아래 구조로 문제를 다시 설계하세요.

[먼저 정할 것]
1. 요청한 단원만 사용합니다. “A와 B”는 두 단원이며 그 사이 단원까지 포함한다는 뜻이 아닙니다. 범위가 불명확하면 질문하거나 확인 가능한 자료 안에서만 구성하세요.
2. P1~P8마다 교과의 어떤 개념을 판단할지 먼저 정합니다. 그 개념에 맞춰 choose(하나 고르기), order(순서 놓기), classify(분류하기) 중 하나를 자유롭게 선택합니다. 과목과 맞지 않는 홀짝, 임의의 숫자 계산, 색깔 규칙을 억지로 붙이지 마세요. 새로운 학습이 없는 같은 판단을 반복해 여덟 문제를 채우지 마세요.
3. 이야기의 장소·소품·등장인물·P9 사진 관찰·P10 수납함 잠금은 유지합니다. 수업의 교과 내용은 P1~P8에만 넣습니다. 새 등장인물, 이동 버튼, 암호 입력칸, 없는 조작을 만들지 마세요.

[방탈출 장치에 맞춰 작성]
각자 탐색 화면의 서로 다른 사물을 조사해 개인 단서를 찾고, 찾은 단서를 모아 장치를 풉니다. 한 단계에 자리별 1개, 전체 P1~P8에서 여러 기록을 누적해서 발견합니다. 단서함은 미발견·발견·사용 완료를 구분하고, 발견 장소와 사용할 장치를 표시합니다. 장치 화면에서도 찾은 개인 단서를 다시 읽고 확대할 수 있습니다. 단서 제목은 관찰한 정보의 이름, 내용은 비교할 자료를 명시한 짧은 사실로 작성하세요. “이것/저것/위의 자료”처럼 장소를 떠나면 대상을 알 수 없는 표현은 쓰지 마세요. 발견 장소는 게임이 연결하므로 새 탐색 사물이나 클릭 절차를 지문에 만들지 않습니다. 발견 확인 여부로 정답 제출을 막지 않습니다.
P1 붉은 끈 파일(메모/주머니) → 반납 메모 발견
P2 반납 서가(책/자리) → 서아의 책갈피 발견
P3 대여표 서랍(봉투/칸) → 도하의 대여표 발견
P4 보관표 확인 장치(기록표/칸) → 상자 표식 발견
P5 반납함(반납함/칸) → 전달 메모 발견
P6 준비대 연결 장치(연결표/소켓) → 보관표 발견
P7 보관함(상자/칸) → 인수 표식 발견
P8 인수 기록함(기록 봉투/칸) → 교실 사진과 위치표 발견
이 장면의 소품명에 맞춰 자료 표시이름을 붙이고, 공동과제는 “어떤 정보를 바탕으로 무엇을 조작할지”를 한 문장으로 적습니다. “다음을 분류하시오/정답을 고르시오”만 쓰지 않습니다. 예: “실험 기록을 보고 상자를 맞는 칸에 넣어 보관함을 여세요.” 교과 판단 근거를 생략하라는 뜻은 아닙니다.
교과의 실제 자료·측정·문맥을 쪽지에 담되, 정답 위치를 직접 알려 주거나 임의의 색·숫자 변환을 덧붙이지 않습니다. 긴 사연, 실제로 제공하지 않는 사진, 존재하지 않는 입력 장치를 만들지 않습니다. 장치의 외형·발견 보상은 고정이고 각 P의 choose/order/classify 선택은 자유입니다. 모양만 바꾸고 같은 교과 판단을 반복하지 마세요.

[필수: 개인 단서가 없으면 답이 확정되지 않아야 함]
모든 학생에게 같은 공개 답안 카드와 대상이 같은 위치에 보입니다. 자료의 담당은 전부 0입니다. 각 자리에는 모둠단서 한 개씩을 주고, 그 안에는 서로 다른 사실 1~2개만 짧게 적습니다.
교과 지식은 단서를 해석하는 데 쓰고, 실제 관찰값·상황·실험 결과·문맥·증언·관계는 개인 단서에서만 얻어야 합니다. 교과서에서 이미 아는 사실을 단서처럼 다시 적거나, 공개 카드에 있는 내용을 반복하지 마세요. 단서를 읽었다는 확인 버튼으로 제출을 막는 것은 협동이 아닙니다.
예시: 공개 카드에는 “메모 가~라”, 분류함에는 “동사·명사·형용사”, 각자 받은 단서에는 그 메모에 실제 적힌 낱말이 있습니다. 품사를 알아도 다른 친구의 낱말은 알 수 없으므로 물어봐야 합니다. 같은 분류함에 여러 장을 허용하여 마지막 한 장을 남은 칸으로 추측할 수 없게 합니다.
다른 교과도 같은 원리입니다. 수학은 각 기록의 수·측정값, 사회·역사는 자료 속 사건의 맥락이나 사료 조각, 영어는 실제 문장이나 화자 정보, 과학은 실제 관찰·측정 결과, 예체능은 실제 작품·연주·동작의 관찰을 나눌 수 있습니다. 이미 공개된 사례의 정답 설명만 단서로 옮기면 안 됩니다.
네 단서를 모두 적용하면 정답이 정확히 하나여야 합니다. 어느 한 자리의 단서를 빼더라도 최소 두 답이 남아야 합니다. 정답·해설·검증조건을 가리고도 이 성질이 실제 문장으로 성립하는지 별도로 풀어 보세요. 공개 정보와 이미 배운 교과 지식으로 비공개 단서의 내용을 재구성할 수 없어야 합니다.

[형식별 규칙과 조작]
choose: 공개 카드 5~6장(A~E 또는 A~F), 대상 없음. 정답 한 장은 “선택”, 나머지는 “제외”. 학생은 소품 하나를 선택한 뒤 장면의 책 꺼내기·걸쇠 열기 등의 손잡이 버튼을 누릅니다. 제외 이유를 여덟 번 입력하게 하지 않습니다. 네 개인 조건을 모두 적용해야 그 한 장이 남도록 구성합니다.
order: 공개 카드 4장(A~D), 대상 없음. 자료 정답은 1·2·3·4를 한 번씩 씁니다. 학생은 소품 → 첫째~넷째 자리(소켓)를 눌러 배치한 뒤 손잡이나 레버를 작동합니다. 연대·과정처럼 공개 내용만으로 전체 순서가 정해지는 배열은 피합니다. 나눠 가진 실제 사건 기록·관찰에서 교과상 관계를 해석해야 합니다.
classify: 공개 카드 4장(A~D), 대상 2~4개(T1~T4). 정답은 대상ID. 같은 대상에 여러 장이 들어갈 수 있고 분류함별 정답 개수를 미리 알려 주지 않습니다. 학생은 소품 → 분류함을 누른 뒤 장치를 작동합니다. 교과상 맞는 분류만 사용합니다. 공개 사례만 읽어도 분류되는 문제를 만들지 마세요.
모든 형식에서 교과 지식이 필요하고, 동시에 다른 친구의 실제 정보도 필요해야 합니다. 정답 위치나 카드 이름 패턴을 보고 찍을 수 없게 섞으세요.

[검증조건: 교사용 판정 정보, 학생에게 전송되지 않음]
각 개인 단서가 허용하는 답을 형식화합니다. 먼저 실제 단서를 작성하고 독립적으로 풀어 본 다음, 정확히 같은 뜻을 검증조건에 적으세요. 정답을 통과시키려고 사실과 다른 조건을 꾸며 넣지 마세요.
choose에서는 그 단서 하나와 일치하는 모든 자료ID를 |로 연결합니다. 예: A|C|E. 맞는 정답 하나만 쓰면 네 단서가 모두 필요한 검사를 통과하지 못합니다.
order 문법:
 A<B : A가 B보다 앞. 바로 앞이라는 뜻은 아님.
 A>B : A가 B보다 뒤.
 A=2 : A가 두 번째. A!=4 : A는 마지막이 아님.
 A~B : 두 카드가 이웃함. A!~B : 이웃하지 않음.
classify 문법:
 A=T1 : A는 T1에 속함. A!=T2 : A는 T2가 아님.
여러 조건을 모두 만족해야 하면 ;로, 대안 중 하나면 |로 연결합니다. ;가 먼저 묶입니다. 괄호·임의 코드·자바스크립트·알 수 없는 연산자는 금지입니다.
순서형의 형식 예시(문장과 교과 의미는 수업에 맞게 새로 구성): 1번 A>B / 2번 A!~B / 3번 A>D / 4번 A!=4 → 유일한 순서는 B,D,A,C. 각각 하나를 빼면 가능한 순서는 2·2·2·5개입니다. 이 예시를 여덟 문제에 그대로 반복하지 마세요.
업로드 검사는 가능한 선택·24가지 순서·모든 분류 배치를 열거해 (1) 전체 조건의 정답이 하나인지 (2) 자료 시트 정답과 같은지 (3) 네 조건 중 하나를 빼면 둘 이상인지 확인합니다. 문장과 조건의 의미 일치, 교과 정확성, 공개 지식으로 단서를 대체할 수 있는지까지 자동 보증하지 않습니다. 작성자가 반드시 검사합니다.
해설에는 교과상 판단 근거, 최종 답, 각 자리의 정보를 하나씩 뺐을 때 남는 서로 다른 답 두 개를 적어 검산할 수 있게 합니다.

2. 6개 시트, P1~P8, 모둠단서 32행, 형식별 카드·대상 수, 글자 제한을 확인합니다.
3. 판정 열과 해설을 가리고 학생 자료만으로 독립적으로 풀어 정답과 비교합니다.
4. 검증조건을 모두 적용한 답은 하나, 어느 한 조건을 빼도 둘 이상인지 열거합니다. 선언한 정답과 일치해야 합니다.
5. 공개 내용+교과 지식만으로는 확정 불가, 각 자리 단서 하나씩 제거해도 확정 불가인지 실제 문장으로 검사합니다. 단서가 공통자료·힌트·그림·카드에 중복되지 않는지 확인합니다.
6. 학생이 각자 실제 정보 1~2개를 공유하고 간단한 조작으로 답할 수 있는지 확인합니다. 모든 문제를 같은 기계적 조건으로 복제하지 않습니다.
7. 저장한 .xlsx를 다시 열어 값과 셀 내용을 확인하고 한 파일로 제공합니다. 실제 업로드·미리보기를 하지 않았다면 했다고 쓰지 마세요.
