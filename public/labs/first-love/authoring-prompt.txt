오늘, 너에게 — 교과 자료 작성 프롬프트 v3

첨부한 오늘너에게_공통교과양식_v3.xlsx와 교과 자료를 사용해 수업용 .xlsx 한 파일을 작성하세요.
수업명: [입력] / 과목: [입력] / 학년: [입력] / 단원·성취기준: [입력]
학생이 읽을 실제 원문·그림·자료: [첨부 또는 입력]
자료가 없으면 임의의 사실을 교과서 내용으로 꾸미지 말고 필요한 범위를 먼저 확인하세요.

[이야기와 역할 — 고정]
축제 정리 중 도하가 윤재의 파란 편지 봉투를 체험 부스 소품과 함께 수납함에 넣었습니다. 네 친구가 남아 있는 부스 장치를 풀어 편지를 되찾습니다.
자리 1=윤재, 2=도하, 3=시우, 4=민우입니다. 선택은 개인 단서를 맡는 역할 선택이며 고백 주인공은 항상 윤재입니다. 서아는 선택 대상이 아닙니다. 친구들은 편지를 찾은 뒤에야 물러납니다.
이야기와 대사를 문제 설명에 덧붙이지 마세요. 긴 서술 대신 장치 조작 한 줄과 각자의 짧은 원자료를 제공합니다.

[열 단계 — 고정 장치와 학습 자료를 구분]
P1 classroom / riddle : 수수께끼가 가리키는 사물과 숨은 배치도 조각 찾기. 양식 그대로 유지.
P2 classroom / jigsaw : 배치도 네 조각 이동·회전. 양식 그대로 유지.
P3 library / dials : 서로 다른 네 자료를 해석해 네 다이얼 맞추기. 교과 교체 영역.
P4 library / circuit : 네 입력선과 여섯 출력 단자를 연결. 교과 교체 영역.
P5 club / tools : 거울로 틈 안 관찰 → 집게로 필름 회수. 양식 그대로 유지.
P6 club / film : 투명 필름을 움직이고 돌려 겹치기. 양식 그대로 유지.
P7 corridor / frames : 여섯 그림·자료 중 네 장을 골라 액자에 배치하고 앞뒤 맞추기. 교과 교체 영역.
P8 corridor / key : 네 열쇠 조각의 자리와 앞뒤를 맞춰 조립. 교과 교체 영역.
P9 교실 사진 대조·점검 열쇠 사용 / P10 실제 수납함 순서 입력은 공통 단계. 퍼즐 행을 추가하지 않습니다.
P1·P2·P5·P6은 프로그램의 고정 퍼즐로 실행됩니다. 해당 행을 바꾸어도 교과 문제가 되지 않습니다.

[모든 교과 공통 설계 원칙]
국어의 원문·문맥, 사회의 지도·사례, 과학의 그림·관찰, 수학의 조건·표, 영어의 상황·표현처럼 해당 과목의 자연스러운 자료를 사용합니다.
홀짝·숫자 크기·연대순·과정 순서를 모든 내용에 억지로 적용하지 않습니다. 순서가 없는 내용은 자료와 설명/대상/사례의 대응으로 만듭니다. 열쇠의 1~4번 홈은 장치의 위치이며 지식 자체가 시간순이어야 한다는 뜻이 아닙니다.
배운 개념을 적용해야 풀리게 하고, 단순히 문장에 적힌 정답 단어를 찾아 복사하는 문제로 만들지 않습니다.
한 공개 질문에 정답 후보 하나를 선택하는 방식은 쓰지 않습니다. 네 다이얼 또는 네 연결 또는 네 배치 전체를 한 번에 판단하는 구조를 유지합니다.

[단서가 실제로 필요한지]
P3·P4·P7·P8은 네 역할의 서로 다른 원자료를 모아야 전체 답을 결정할 수 있어야 합니다.
개인 자료의 내용은 주변 사물을 발견한 해당 역할에만 보입니다. 공개 자료에는 답을 판단하는 데 필요한 개인 관찰값을 중복하지 마세요.
한 문장을 네 조각으로 잘라 나누거나 각자 정답 번호만 알려 주지 마세요. 각 역할에 읽고 해석할 실제 문장·관찰·사례를 줍니다.
각 단서에는 연결되는 다이얼/입력선/액자/홈 번호가 분명히 있어야 합니다. 학생이 어떤 자료를 어디에 쓸지 추측하게 만들지 마세요.
검산 방법: 정답 열을 가리고 네 역할 자료로 전체 답을 구합니다. 이어 한 역할의 자료를 빼고 나머지 자료만 보았을 때 가능한 전체 답이 최소 두 개 남는지 각각 확인합니다. 예를 들어 마지막 열쇠의 자리만 남은 조각으로 추론돼도 앞뒤는 그 역할의 자료를 읽어야 결정되도록 합니다.
해설에는 교과상 판단 근거, 전체 답, 단서를 하나씩 뺐을 때 남는 서로 다른 답의 예를 기록합니다. 형식 검사 통과를 내용 검증 완료라고 표현하지 마세요.

[파일 구조와 글자 제한]
6개 시트 이름과 열 이름, 퍼즐ID·장소·형식·자료ID·담당·장치 값을 유지합니다. 수식·매크로·외부 연결 없이 값으로 작성합니다.
설정: 항목 / 값 / 설명
퍼즐: 퍼즐ID / 장소 / 형식 / 제목 / 공동과제 / 공통자료 / 해설 / 힌트1 / 힌트2 / 힌트3
자료: 퍼즐ID / 자료ID / 표시이름 / 내용 / 담당 / 정답 / 중간정답 / 기준자료 / 조건통과 / 그림주소 / 그림설명
대상: 퍼즐ID / 대상ID / 종류 / 표시이름  (v3는 헤더만 유지. 데이터는 넣지 않음)
모둠단서: 퍼즐ID / 자리 / 제목 / 내용  (v2의 검증조건 열은 사용하지 않음)
장치: 항목 / 값 / 설명
설정 양식버전은 TODAY-TO-YOU-3. 미소_최대오답=5, 당황_최대오답=14를 기본으로 유지합니다.
공동과제 65자, 공통자료 120자, 해설 2000자, 각 힌트 90자 이내.
공개 자료 표시이름 18자, 내용 50자, 그림설명 100자 이내. 개인 단서 제목 24자, 내용 150자 이내. 가능하면 개인 단서는 1~2문장, 90자 이하로 씁니다.
자료 내용과 그림의 세부는 학생 화면의 ‘자료 보기’에서 확대할 수 있습니다. 핵심 구분 정보는 작은 그림만으로 알 수 있게 강요하지 마세요.
모둠단서는 P1~P8마다 자리 1~4 한 행씩, 총 32행입니다. P3·P4·P7·P8의 단서만 교체합니다.

[장치별 정답 입력 규칙]
P3 dials: 자료 A~F 총 6개. 각 자료는 다이얼에서 선택할 표시입니다. 정답 열에는 그 표시를 써야 하는 다이얼 번호를 적습니다. 예: B가 1번 다이얼이면 B의 정답=1. 같은 표시를 1·3번에서 쓰면 1|3. 쓰지 않는 표시는 빈칸. 전체 자료의 정답을 모으면 1,2,3,4가 각각 한 번 있어야 합니다.
P4 circuit: 자료 A~F 총 6개. 각 자료는 출력 단자입니다. 정답 열은 해당 단자에 연결할 입력선 번호입니다. 한 단자에 여러 선이 연결될 수 있으며 1|3처럼 적습니다. 네 입력선 번호를 각각 한 번 배정합니다.
P3·P4의 중간정답·기준자료·조건통과는 비웁니다. 담당은 모든 자료에서 0입니다.
P7 frames: 자료 A~F 총 6개. 정답에 액자 자리 1~4를 각각 한 번 쓰고 나머지 두 장은 제외. 중간정답에는 앞면 0 또는 180도 뒤집음 1. 뒷면은 실제 그림이 180도 돌아가는 방식이므로 그림·표식의 방향과 단서가 모순되지 않아야 합니다.
P8 key: 자료 A~D 총 4개. 정답에 열쇠 홈 1~4를 각각 한 번 배정. 중간정답에는 앞면 0 또는 뒤집음 1. 원래 학습 내용에 방향 개념이 없으면 방향 표식을 가진 원자료와 관계를 읽게 할 수 있지만, 지식의 순서를 꾸며 내지 마세요.
P7·P8의 기준자료·조건통과는 비우고 담당은 0입니다.
자료ID는 장치마다 A부터 차례로 유지합니다. 정답은 프로그램이 학생에게 보내지 않습니다.

[그림]
P7에는 교과의 실제 그림·지도·도표·원문 조각을 적극 사용하세요. 제공 자료가 없으면 학습 그림인 척 임의로 만들어 넣지 마세요.
자료 시트의 해당 데이터 행 위에 그림 한 장씩 배치하고 왼쪽 위 모서리가 그 행 안에 오게 합니다. PNG·JPG·WEBP 한 장 500KB 이하, 파일 전체 3MB 이하. 그림주소는 비우고 그림설명에 대체 설명을 적습니다. 셀 안 그림·웹주소·SVG·GIF는 사용하지 않습니다.
시연용 모양·학교 소품 예시는 장치 사용법을 보여 주는 자료이며 선택한 단원의 학습 문항으로 간주하지 않습니다.

[학생 행동과 피드백]
장치·단서·버튼은 한 화면에서 볼 수 있고 긴 자료는 페이지로 넘깁니다. 스크롤을 전제로 길게 쓰지 마세요.
조사·도구 선택·조각 회전·이동은 오답이 아닙니다. 전체 답안을 명시적으로 제출한 경우만 판정합니다. P1·P5·P6·P9는 탐색/시각 관찰로 오답에 넣지 않습니다.
맞은 칸, 맞힌 개수, 맞는 조각만 붙는 자동 스냅, 부분 정답 잠금을 요구하지 마세요.
힌트는 관찰할 대상 → 배운 개념의 적용 → 조작 방법 순서로 세 단계. 다른 역할의 비밀 자료나 완성 답을 공개하지 않습니다.

[납품 전 확인]
1. 참고 자료와 학년·성취기준·용어·사실·단위·그림 방향을 대조합니다.
2. 여섯 시트와 P1~P8, 학습형 네 장치의 자료 수·정답 연결·앞뒤 값을 확인합니다.
3. 정답 열을 가리고 독립적으로 풀어 정답·해설과 비교합니다.
4. 각 역할 단서를 하나씩 빼서 전체 답이 최소 두 개 남는지 실제 문장으로 검산합니다.
5. 공개 자료·공통자료·힌트에서 개인 단서의 내용이 중복되거나 정답이 그대로 드러나지 않는지 확인합니다.
6. 저장한 .xlsx를 다시 읽어 값을 확인하고 한 파일로 제공합니다. 실제 업로드·미리보기를 하지 않았다면 했다고 쓰지 마세요.
