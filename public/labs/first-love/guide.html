네 친구가 되찾는 편지

축제 정리 중 도하가 윤재의 파란 편지 봉투를 체험 부스 수납함에 넣어 잠가 버렸어요. 네 친구는 남아 있는 장치를 풀어 봉투를 되찾습니다.

윤재·도하·시우·민우 중 고르는 것은 담당 역할과 개인 단서입니다. 고백하는 사람은 항상 윤재예요. 서아는 자기 전시물을 정리하고 약속 장소로 옵니다.

4인 협동 · 열 단계 · 약 40분
수수께끼, 그림 조각, 다이얼, 전선, 거울과 집게, 필름, 그림판, 열쇠, 사진, 수납함이 이어집니다.

발견 → 공유 → 장치 조작

  • 수업 코드로 입장하고 모둠원마다 서로 다른 역할을 고릅니다.
  • 탐색 화면에서 내 인물 이름이 붙은 사물을 눌러 단서를 찾습니다.
  • 아래 ‘내 역할 · 단서함’에서 발견 내용·찾은 곳·쓸 곳을 확인합니다. 대화 중에도 열 수 있어요.
  • 장치를 열어 친구의 단서와 함께 답을 맞춥니다. 단서는 넘겨 보며, ‘자료 보기’로 원자료를 확대합니다.
  • 빈 역할의 자료는 남은 친구가 함께 볼 수 있습니다. 혼자 체험에서는 네 역할 자료를 모두 볼 수 있어요.

네 학습 장치만 교과에 맞게

새 v3 양식은 P3·P4·P7·P8의 원문·그림·사례·관계를 바꾸어 사용합니다. P1·P2·P5·P6은 이야기 고정 퍼즐이고, P9·P10도 공통 장치입니다.

단원에 시간순이 없다면 억지로 순서를 만들지 마세요. 다이얼·입력선·액자·열쇠 홈과 자료를 대응시키면 됩니다. 홀짝 규칙은 필수 요소가 아닙니다.

엑셀 업로드 → 역할별 미리보기 → 수업 만들기 → 코드 공유 → ‘모든 모둠 시작’ 순으로 진행합니다. 기존 v1·v2 파일은 기존 방식으로 실행됩니다.

v3 엑셀 양식교과 작성 프롬프트

정답 연결을 이렇게 적어요

장치자료정답 / 중간정답
P3 다이얼A~F 표시 6개해당 다이얼 1~4 / 빈칸
P4 전선A~F 단자 6개연결할 선 1~4 / 빈칸
P7 그림판A~F 그림 6개액자 1~4, 나머지 제외 / 앞 0·뒤 1

다이얼·단자의 같은 자료를 여러 번 쓰면 1|3처럼 적습니다. 각 번호는 한 번씩 배정해요. 개인 단서는 역할마다 서로 달라야 합니다. 각 단서를 하나씩 빼도 가능한 전체 답이 두 개 이상 남는지 확인하세요.

형식 검사는 내용의 정확성까지 보증하지 않습니다. 세부 작성법과 제한은 작성 프롬프트에 있습니다.

전체 답안만 한 번에 확인

조사·물건 선택·조각 이동·회전은 오답이 아닙니다. P1·P5·P6·P9의 탐색도 오답에 넣지 않습니다. 빈 답안과 같은 답의 중복 전송도 다시 세지 않아요.

기본 기준은 0~5회 미소, 6~14회 당황, 15회 이상 거절입니다. 10회는 당황 구간에 포함됩니다. 수업 생성 전에 교사가 기준을 바꿀 수 있어요.

마지막은 시작 칸까지 포함해 수납함 버튼을 순서대로 누릅니다. 같은 칸을 다시 지나면 같은 버튼을 또 눌러요. 중간에 맞은 버튼은 알려 주지 않습니다.

단서가 안 보이면 발견했는지, 담당 역할이 맞는지 확인해 주세요. 저장한 진행은 같은 기기에서 이어 할 수 있습니다.
