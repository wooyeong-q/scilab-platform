# Korean classroom typeface

Noto Sans KR variable font, distributed under the SIL Open Font License in OFL.txt.
Source: https://github.com/google/fonts/tree/main/ofl/notosanskr

`noto-sans-kr.woff2` is a variable WOFF2 subset containing the characters used by this lab's HTML, MJS and CSS plus ASCII. FontTools was used to subset the upstream `NotoSansKR[wght].ttf`. The font is served locally, with no third-party font request. Add characters to the subset if future lesson text introduces characters not covered. A system sans fallback remains available.
